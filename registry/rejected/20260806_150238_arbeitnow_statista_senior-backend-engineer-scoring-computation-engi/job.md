**About the role**

You will build the core engine that powers our rankings and benchmarks for hospitals worldwide: a versioned, fully reproducible computation layer that transforms harmonized metrics into comparable scores.

The focus of this role is **algorithmic computation, mathematical correctness, and system reproducibility**—web application development is a limited aspect of this system. As the senior technical owner for this area, you will design how scoring definitions, formula trees, category mappings, and peer-group logic are modeled as data and executed deterministically over time.

**Key Responsibilities**

-

**Engine Architecture:** Design and build the core scoring engine—a typed, versioned computation graph (DAG) executed deterministically with clear boundary contracts.

-

**Methodology as Data:** Model complex business logic (formula trees, categorical mappings, peer selection, and comparability adjustments) as versioned, declarative data structures.

-

**Determinism & Lineage:** Own system lineage, versioning, and execution auditability end-to-end, ensuring any score can be recalculated identically at any future date.

-

**Internal Tools & API Layer:** Build clean, typed services and contracts for our internal methodology workbench and downstream consumer applications.

-

**Testing & Quality Discipline:** Establish rigorous testing practices (e.g., golden file testing, property-based testing, regression validation) to prevent calculation drift.

-

**Technical Ownership:** Shape architecture, drive trade-offs between execution speed and cost, set code review standards, and mentor joining engineers.
