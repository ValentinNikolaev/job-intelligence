## **About the Role**

- Design and develop backend services in Kotlin and Spring Boot

- Build and maintain REST APIs used by internal and external partners

- Participate in architectural decisions and technical modernization initiatives

- Improve observability, performance, and reliability of backend systems using DataDog

- Contribute to CI/CD pipelines and cloud infrastructure on AWS and Kubernetes

- Work in and contribute to an AI-native development environment — including AI-integrated code review automation and an internal Claude Code plugin marketplace covering engineering standards: Kotlin/Spring Boot conventions, architectural patterns, testing practices, database guidelines, and team-specific conventions.

## **About You**

- 5+ years of professional backend development experience with JVM languages with at least 2 years of commercial experience with Kotlin

- Hands-on experience with Spring Boot

- Experience building and maintaining REST APIs and distributed systems

- Solid SQL knowledge and relational database design, including MySQL and PostgreSQL

- Sound software engineering fundamentals, clean code practices, and familiarity with ORM and persistence layers

- Collaborative and pragmatic, comfortable working in cross-functional Agile teams

- Preferred: AWS, Kubernetes, GitLab CI/CD, Kafka, Terraform, LLM integrations, RAG systems, AI product development, or legacy system migration experience
