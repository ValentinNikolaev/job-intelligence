### About the Role

Thousands of engineers rely on this platform daily to inspect traces, iterate on prompts, and run experiments across their LLM applications. Full LLM inputs and outputs can span tens of thousands of tokens — your job is to make that experience **fast, intuitive, and effortless**.

You love profiling React renders. You know when to virtualize, memoize, or restructure state. The data is massive — the interface should never feel like it is. As a Senior Frontend Engineer, you'll own the performance and architecture of a complex, data-intensive web application used at scale by AI engineers worldwide.

### What You'll Do

-

**Build performant trace views** — Own the rendering of large LLM data: identify bottlenecks, optimize data loading, and reduce re-renders so even the largest agent traces feel snappy.

-

**Own the React architecture** — Shape how components are built, code is structured, and tests are written. Keep the codebase current with React Compiler and emerging patterns.

-

**Design and implement data visualizations** — Build rich, interactive charts and tables that surface cost, latency, and quality signals from high-volume analytical data.

-

**Drive frontend quality** — Write and advocate for unit, integration, and end-to-end tests. Establish standards for code reviews and mentor peers across a small, cross-functional team.

-

**Collaborate cross-functionally** — Work closely with product, design, and backend engineers to ship features end-to-end across the LLM development lifecycle — tracing, evaluation, prompt management, experiments, and more.

-

**Contribute to open source** — A significant portion of the codebase is public; your work will be seen and used by a large developer community.
