**Mission Brief**

As an Application Software Engineer in the Ground Systems Engineering Applications team, you will help shape the digital tools that enable the testing and operation of our launch vehicles. Your work will have a direct impact on critical ground operations, supporting engineers and operators

throughout the development lifecycle.

More specifically, you will:

- Develop, enhance, and maintain desktop applications

- Automate engineering workflows and improve operational efficiency

- Design scalable, maintainable software architectures

- Optimize performance, responsiveness, and user experience

- Extend internal libraries and deliver elegant technical solutions

- Create technical and user documentation

**Qualification Checklist**

• Experience developing desktop applications using C#, .NET, and WPF (or similar technologies such as Avalonia or MAUI)

• Strong understanding of object-oriented programming and software design principles

• Experience applying architectural patterns such as MVVM, MVC, and MVP

• Proficiency with version control systems, particularly Git

• Experience with unit testing, ideally using NUnit and test-driven development (TDD)

• Commitment to clean code principles and delivering high-quality, maintainable software

**Bonus Skills**

**•** Experience working with REST APIs

• Understanding of infrastructure, cloud services and network.

• Experience in a major front-end framework (preferably React)

• Experience with the Aerospace Engineering domain use cases.
