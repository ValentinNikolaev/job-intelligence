🎯 Your main goal will be to design and evolve the frontend platform foundations that power n8n’s workflow-building experience, enabling product engineers and the open-source community to ship complex, reliable, and high-performance user experiences across cloud and self-hosted deployments.

As part of the team, you’ll take ownership of core frontend platform domains and help shape the architecture behind one of the most flexible automation products in the market:


FRONTEND PLATFORM ARCHITECTURE

 - Own and evolve core frontend platform primitives that make n8n’s workflow builder scalable, extensible, and maintainable.

 - Strengthen platform contracts such as plugin systems, extension points, and frontend developer experience.

 - Help modularize a large, evolving frontend codebase so product teams can build confidently on top of shared foundations.


CANVAS, COLLABORATION, AND REAL-TIME SYSTEMS

 - Work on the architecture behind n8n’s canvas-based workflow building experience.

 - Build and improve real-time collaboration capabilities using approaches such as WebSockets, CRDTs, or multiplayer synchronization patterns.

 - Design frontend systems with correctness, accessibility, and user experience in mind, especially for complex interactive workflows.


PERFORMANCE AND RENDERING FOUNDATIONS

 - Improve rendering performance, runtime behavior, and responsiveness across complex workflow-building experiences.

 - Use performance measurement, profiling, and optimization techniques to identify bottlenecks and improve user experience.

 - Contribute to web worker orchestration and other frontend infrastructure that helps n8n scale to more complex use cases.


TECHNICAL CONTRIBUTION AND COLLABORATION

 - Drive technical decisions through clear proposals, RFCs, and collaborative engineering discussions.

 - Partner closely with product engineers, QA, DX, Security, Staff Architects, and the open-source community to ensure platform changes integrate smoothly.

 - Support peers through code reviews, pairing, mentoring, and knowledge sharing.
