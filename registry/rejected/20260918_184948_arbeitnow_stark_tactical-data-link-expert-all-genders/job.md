**Your mission**

Support the development, integration, testing, and operational use of tactical data link capabilities for STARK’s unmanned systems, Ground Control Stations, and wider command-and-control environments. You will help ensure that our systems can communicate reliably and securely with military networks, command posts, allied platforms, and mission systems. A key part of the role is to evaluate, understand, and integrate tactical communication standards and technologies such as Link 16, Link 22, SATCOM, and other military data link solutions. You will translate operational communication requirements into practical integration concepts, test setups, and deployable system configurations.

**Responsibilities**

Tactical Data Link Integration: Support the integration of tactical data link capabilities such as Link 16, Link 22, SATCOM, and other military communication systems into STARK platforms and Ground Control Station environments.

Interoperability Concepts: Define and support communication concepts that enable reliable data exchange between unmanned systems, GCS setups, command centers, allied platforms, and external mission systems.

Requirements Translation: Translate operational and military communication requirements into technical integration requirements, interface definitions, test needs, and subsystem-level implementation concepts.

System Interface Support: Work with engineering, software, network, RF, modem, antenna, and GCS teams to align interfaces, protocols, data flows, configuration requirements, and integration constraints.

SATCOM & Beyond-Line-of-Sight Support: Support concepts and integration activities for SATCOM, long-range communication paths, and other beyond-line-of-sight connectivity options.

Testing & Validation: Plan and support lab tests, field tests, interoperability checks, and validation activities for tactical data link and communication setups.

Security & Reliability: Contribute to secure, robust, and mission-ready communication architectures, considering availability, latency, data integrity, authentication, and operational constraints.

Supplier & Partner Coordination: Work with external suppliers, partners, military stakeholders, and internal teams to assess data link options, integration dependencies, and technical feasibility.

Documentation: Document data link concepts, interface assumptions, configuration settings, integration dependencies, test results, and recommended operational setups in a clear and maintainable way.

Problem-Solving Ability: Strong analytical mindset with the ability to identify communication issues, integration gaps, configuration problems, and practical solutions.

Communication: Solid English skills are required. German skills for technical communication, stakeholder alignment, and documentation are a plus.

Team Fit: Ability to work collaboratively in a small, cross-functional team and communicate clearly and reliably in fast-moving engineering environments.
