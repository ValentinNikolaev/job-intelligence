## What you’ll do:

As part of our development team, you’ll build websites and features from design references, turning Figma files into clean, maintainable, production-ready code. Our primary stack is built on Gutenberg block themes, so you’ll spend most of your time there, though you may also work on traditional WordPress themes and, occasionally, other page builders.

- Build websites and site features from design references, using industry-standard code and best practices

- Develop and maintain WordPress block themes using Gutenberg, templates, parts, patterns, and theme.json configuration

- Work with traditional WordPress themes when needed, and occasionally with other page builder platforms

- Write clean, well-structured HTML, CSS, and JavaScript

- Build or extend front-end functionality using React or similar component-based approaches when the project calls for it

- Use Git and GitHub for version control, following team branching and code review conventions

- Work within a continuous deployment workflow, ensuring changes move smoothly and safely from development to production

- Troubleshoot cross-browser and cross-device issues to ensure consistent, polished results

- Collaborate with designers, project managers, and strategists to bring projects to life

- Look for new and more efficient ways to deliver our work, whether that’s through better tooling, reusable components, or refined processes

- Contribute to internal documentation, component libraries, and knowledge sharing

- Stay current with WordPress, Gutenberg, and front-end development trends and best practices

- Familiarity with Git workflows and collaborative development practices

- Experience working within a continuous deployment or CI/CD pipeline
