**Your impact at gridX**

As a Junior Software Engineer on the Platforms Team, you’ll play a key role in bridging the gap between external cloud ecosystems and the gridX platform. As part of the Cloud Connector team, your work is the bridge between the gridX platform and the outside world. You will build and maintain the backend services that allow us to seamlessly integrate with external energy providers. Your code will turn complex, varied external APIs into standardized, reliable connections that the rest of our engineering organization relies on. By developing robust APIs and smart integration tools, you empower gridX to onboard new cloud assets faster, making energy management seamless for our customers and platform partners alike.
Are you ready to #makeamark, #getshitdone, and build the future of energy? Apply now and join our mission!

Please note: We only accept applications from candidates who are currently located in Germany.

**How you can contribute to gridX**

What you’ll work on

- Integrations with partners: Your primary focus is seamlessly integrating various cloud providers into our ecosystem. This involves implementing and maintaining Go services that abstract away provider-specific edge cases, allowing us to reliably gather measurements and send control commands. You'll work closely with API specs, frequently leveraging AI coding tools to accelerate your implementation and review cycles.
- Fast scaling: You’ll engineer solutions for a fast-scaling platform handling around 20.000 cloud-connected assets. With our managed fleet growing over 80% the past 6 months, you’ll play a critical role in designing architecture that handles heavy telemetry and real-time control at scale.
- Cross-team Collaboration: The Cloud Connector is the critical bridge connecting physical devices to gridX’s wider platform architecture. You'll build the cloud integrations that link assets to our platform, ingest asset data for various services, and route real-time execution commands back to the assets via cloud providers.

We use AI-assisted and agentic coding workflows extensively, from code generation and review to spec analysis and test creation. You'll be expected to leverage these tools effectively and help actively shape our evolving engineering culture.

Day-to-day, that means

- Implementing new cloud integrations based on API documentation, OAuth specifications, and webhook contracts.
- Evolving the integration framework, refactoring event-processing chains, migrating data stores, and shaping the abstractions that make future integrations simpler.
- Debugging distributed pipeline failures using structured logs, distributed traces, and metrics, across OAuth flows, webhook processing, and event delivery.
- Writing tests that cover provider API contracts, webhook edge cases, command delivery reliability, and distributed failure modes.
- Contributing to API specifications (TypeSpec/OpenAPI, protobuf/gRPC) that connects to downstream gridX services and external partners.
- Collaborating with cloud API teams, Product Owners, Platform Engineers, and Energy Domain Experts.
