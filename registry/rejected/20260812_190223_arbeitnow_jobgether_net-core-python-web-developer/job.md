**This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a .NET Core & Python Web Developer based in Germany.**

This role is an opportunity for a senior software engineer to build and support enterprise-grade applications using .NET Core and Python. You will focus on backend and web application development, including APIs, services, and microservices, rather than data engineering or data science. You will contribute to cloud-native solutions deployed within Microsoft Azure environments. The position combines hands-on development with architecture, testing, troubleshooting, and modern DevOps practices. You will collaborate with architects, QA, product, DevOps, and engineering teams in an Agile environment. Your work will directly contribute to secure, scalable, maintainable, and reliable business applications.

**Accountabilities**

- Design, develop, test, enhance, and maintain enterprise applications using **.NET Core and Python**, with Python focused specifically on web, backend, API, and application development.

- Build scalable backend services, REST APIs, web services, and microservices for enterprise applications.

- Develop and support **Azure-based microservices and cloud-native applications**, ensuring reliability, scalability, and maintainability.

- Design and integrate RESTful APIs across applications and enterprise platforms.

- Work with **SQL Server and Azure SQL** for application data access, database development, queries, stored procedures, and performance optimization.

- Contribute to application architecture, technical design, coding standards, peer reviews, and engineering best practices.

- Develop unit tests and automated tests to maintain application quality and reduce production defects.

- Use **Azure DevOps** for source-code management, work tracking, automated testing, continuous integration, and deployment/release pipelines.

- Apply **Git** for version control, branching, merging, and collaborative software development.

- Investigate and resolve application, API, database, integration, and production issues.

- Collaborate closely with architects, product teams, QA, DevOps, and other engineering stakeholders to deliver solutions effectively.

- Participate in Agile ceremonies, including sprint planning, backlog refinement, stand-ups, reviews, and retrospectives.

- Produce clean, secure, maintainable, and well-documented code while contributing to continuous improvement across development practices.

### **Requirements**

- **7+ years of professional software development experience** with .NET and .NET Core.

- **4+ years of Python application development experience**, specifically in web, backend, API, services, or microservices development rather than data engineering or data science.

- **4+ years of experience with Azure-based microservices** and cloud-native application development.

- **5+ years of experience with SQL Server and/or Azure SQL**, including queries, stored procedures, application data access, and performance optimization.

- **5+ years of hands-on Azure DevOps experience**, including code repositories, work-item tracking, automated testing, CI builds, and release/deployment pipelines.

- Strong proficiency with **Git**, REST APIs, web services, and distributed or microservices-based applications.

- Solid understanding of object-oriented programming, software engineering principles, architecture concepts, and design patterns.

- Proven experience debugging, troubleshooting, and supporting production applications.

- Strong analytical, problem-solving, and communication skills, with the ability to collaborate effectively across technical teams.

- Comfortable working in an Agile development environment and managing responsibilities across the full software development lifecycle.

### **Benefits**

- Contract opportunity focused on modern enterprise software engineering and cloud technologies.

- Remote work environment with the flexibility associated with a distributed position.

- Opportunity to work extensively with **.NET Core, Python, Microsoft Azure, Azure DevOps, SQL Server, Azure SQL, REST APIs, and microservices**.

- Exposure to enterprise-scale application architecture, cloud-native development, CI/CD, and DevOps practices.

- Collaboration with architects, product teams, QA, DevOps professionals, and other engineering specialists.

- Opportunity to contribute to scalable, secure, and production-grade applications across a modern technology environment.
