### Responsibilities:

-

Lead the design, implementation, and optimization of production services and APIs using Rust.

-

Contribute to our Vue and Angular frontend applications as project needs require, ensuring cohesive user experiences.

-

Support and interface with our underlying AWS Glue data pipelines, data models, and backend storage.

-

Design high-performance asynchronous systems, establish robust unit/integration testing, and optimize database queries.

-

Collaborate with team members to break down end-to-end features, communicate backend decisions clearly, and ship reliable software.

-

Proven experience building and deploying backend services in Rust.

Strong async programming, API design, data modeling, and testing skills.

Fluency in English with strong collaboration and team skills.
