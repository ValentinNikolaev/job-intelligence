We are looking for a talented Senior Full Stack PHP Developer to join our client’s team.

**What is this project about?**
A booking platform for the tours and activities market. This is an established, large-scale product that continues to grow, supporting bookings across multiple channels for tour and activity providers.

**What is the team size and structure?**
A small international team: 2 engineers, DevOps, Lead Engineer, and Project Manager.

**How many stages of the interview are there?**
Recruiter interview — up to 30 minutes;
Technical interview — up to 1 hour;
Client interview — an introductory conversation about experience and cultural/team fit;
Client pair programming / live coding session — to see how the candidate works in a real work environment.

**Requirements and responsibilities**
**Hard skills**

- Strong experience with PHP 8+ and modern backend development practices;
- **Upper-Intermediate or higher English (written and spoken);**
- Solid, hands-on experience with Vue.js for frontend development;
- Strong, production-level experience with MongoDB;
- Experience with message brokers (RabbitMQ) and caching systems (Redis);
- Familiarity with search engines such as Elasticsearch or OpenSearch;
- Strong understanding of cloud infrastructure, preferably AWS (enough to collaborate closely with a DevOps engineer, not hands-on infrastructure management);
- Experience with Infrastructure as Code tools (Terraform, Ansible) is a plus;
- Proficient in working with Linux environments;
- Experience building and maintaining CI/CD pipelines;
- Strong testing mindset with experience in PHPUnit and Test-Driven Development (TDD);
- Familiarity with code quality and static analysis tools (PHPStan, Code Sniffer, etc.);
- Good understanding of Domain-Driven Design (DDD) principles;
- Experience working in a Kanban process;
- Ability to work independently and take ownership of tasks;
- Proactive mindset with strong problem-solving skills;
- Strong communication skills and ability to collaborate with cross-functional teams.

**Nice to have**

- Experience with microservices architecture and event-driven systems;
- Familiarity with Docker Swarm or other container orchestration tools;
- Experience with CircleCI, Datadog;
- Knowledge of frontend performance optimization and modern build tools;
- Experience working in high-load or high-availability systems;
- Understanding of security best practices in web applications;
- Familiarity with AI tools for software development (e.g., Junie, Claude Code, etc.) and prompt engineering.

**Responsibilities**

- Design, develop, and maintain scalable web applications using PHP 8+ and Vue.js;
- Build and integrate backend services with databases such as MongoDB and MySQL;
- Develop and optimize asynchronous and distributed systems using RabbitMQ and Redis;
- Implement and maintain search solutions using Elasticsearch/OpenSearch;
- Collaborate with product and design teams on features and technical solutions;
- Actively participate in architectural decisions following Domain-Driven Design (DDD) principles;
- Write clean, testable, and maintainable code following TDD practices;
- Ensure code quality using tools such as PHPUnit, PHPStan, and Code Sniffer;
- Design, build, and maintain CI/CD pipelines for automated testing and deployment;
- Manage and optimize cloud infrastructure (AWS) in collaboration with the DevOps engineer, using Infrastructure as Code (Terraform, Ansible);
- Work with containerized environments using Docker;
- Monitor, troubleshoot, and improve system performance and reliability;
- Take ownership of tasks in a Kanban-based workflow, driving work from concept to production;
- Work independently while maintaining clear communication and visibility of progress.
