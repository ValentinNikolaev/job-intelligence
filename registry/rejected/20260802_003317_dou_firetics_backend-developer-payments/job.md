Шукаємо Backend Developer, який буде працювати над інтеграцією та розвитком платіжних рішень у iGaming-продукті.

**Обов’язки:**

- Інтегрувати та підтримувати платіжні провайдери.
- Розробляти та розвивати уніфікований шар інтеграцій (payment gateway/adapter layer): стандартизація API, конфігурації, параметрів, статусів, мапінг помилок.
- Реалізовувати обробку callbacks/webhooks: валідація підписів, idempotency, ретраї, дедуплікація, обробка race conditions.
- Будувати надійні фінансові процеси: транзакційність, консистентність, аудит, коректні стани платежу (state machine), безпечні виплати.
- Працювати з reconciliation: звірка платежів з провайдером, розбір розбіжностей, автоматизація звітності/логування.
- Проєктувати гнучку архітектуру платіжного модуля з орієнтацією на довгострокову підтримку та швидке підключення нових PSP.

**Вимоги:**

- PHP 8.x, досвід від 3 років.
- Laravel від 1 року (або еквівалентний досвід Symfony).
- MySQL 5.7–8.0: транзакції, робота з високими навантаженнями, розуміння блокувань/ізоляцій, оптимізація запитів.
- Redis (кеш, сесії/локи, rate limiting).
- Git/GitHub, GitHub flow.
- Сильні навички роботи з API: інтеграція сторонніх API (REST/JSON), побудова власних API, логування, версіонування, документація.
- Досвід інтеграцій із платіжними системами / провайдерами.
- Розуміння типових проблем оплат: idempotency, retries, timeouts, webhook delivery, статуси платежів, chargeback/rollback логіка (на рівні системи), антифрод-патерни.

**Буде плюсом:**

- Досвід з Docker, Nginx, базові DevOps-навички (Debian-подібні системи).
- NodeJS / Socket.io або подієва взаємодія між сервісами (PubSub), Redis як PubSub між PHP та NodeJS/Swoole.
- Черги (Horizon/Redis queues, RabbitMQ).
- Frontend: Vue 3 / Nuxt 3 (як плюс для повного розуміння флоу).

**Що ми пропонуємо:**

- Віддалений формат роботи та гнучкий графік
- Конкурентна зарплата, регулярні рев’ю та бонуси за ініціативу
- Швидкий процес найму — лише 2–3 етапи, і ти з нами
- 24 дні оплачуваної відпустки + 10 sick leaves на рік
- Сильна команда, що ділиться досвідом і знаннями
- Ми не наймаємо тімлідів — ми вирощуємо їх всередині команди
- Бюджети та ресурси для втілення твоїх ідей
- Прозорість і мінімум формальностей
- Комʼюніті, де комфортно: граємо, їздимо на конференції, нетворкаємо і просто класно проводимо час!
