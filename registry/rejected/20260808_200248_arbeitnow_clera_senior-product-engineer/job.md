### About the Role

This is a high-ownership product engineering role at a fast-growing, widely adopted open-source AI engineering platform — think the observability layer for the LLM era. The company is trusted by major enterprises and thousands of developers worldwide, with tens of millions of monthly SDK downloads.

Product engineers here own the full lifecycle of a feature: from talking to users and writing the spec, through shipping the code, to writing the docs and the public changelog post. No handoffs — you see features through from user problem to production.

Recent examples of features owned by a single engineer include a major agents release, a TypeScript SDK rewrite on OpenTelemetry, and a hosted MCP server for prompt management. That's the scope and ambition of this role.

### What You'll Do

-

**Own features end-to-end** — user calls, spec writing, implementation, documentation, and public-facing changelog posts. No handoffs, full accountability.

-

**Work the full stack** — React frontend, Next.js backend, ClickHouse analytics, and Python/TypeScript SDKs. You touch whatever the feature demands.

-

**Build in the open** — write code that ships to the open-source community, respond to GitHub issues, review public PRs, and contribute to developer-facing documentation.

-

**Talk to users** — participate in user interviews and translate feedback into product decisions and engineering solutions.

-

**Contribute to platform observability** — work on tracing, monitoring, evaluation pipelines, prompt management, and cost/latency analytics.

-

**Maintain and distribute SDKs** — help evolve and maintain client libraries used by a large developer community.
