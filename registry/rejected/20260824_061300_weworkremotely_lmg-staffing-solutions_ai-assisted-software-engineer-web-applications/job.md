**Description**

Overview We are looking for a software engineer to build and scale our internal web applications. Your mission is to deliver high-quality, maintainable solutions using a Next.js front end and a Django back end, while actively using AI tools and Model Context Protocols (MCPs) to accelerate development and enforce clean architecture.

What Success Looks Like

- Seamless integration between the Next.js front end and Django back end, maintaining high performance and security.
- Proactive use of AI coding assistants and MCPs to accelerate development cycles and improve code quality, rather than relying on them as a crutch.
- Code is clean, modular, thoroughly tested, and ready for production with minimal technical debt.
- Effective collaboration and clear communication with cross-functional teams to align technical solutions with business needs.

**Requirements**

Core Responsibilities

- Next.js Front End: Develop fast, responsive, and intuitive user interfaces using React and Next.js.
- Django Back End: Architect and build secure, scalable APIs and core business logic using Python and Django.
- Integration & Architecture: Design clean, modular systems that seamlessly connect internal tools, databases, and third-party platforms.
- AI-Assisted Development & MCPs: Leverage AI coding assistants in your daily workflow and build or integrate Model Context Protocols (MCPs) to expand the capabilities of our AI agents.
- Quality Practices: Champion clean code principles, write comprehensive automated tests, and participate in code reviews to ensure system reliability.

Requirements

- Strong proficiency in Python and the Django framework.
- Strong proficiency in JavaScript/TypeScript, React, and Next.js.
- Proven experience in robust API design and third-party integrations.
- A strong commitment to automated testing, clean architecture, and modern QA practices.
- Familiarity with cloud basics, containerization (Docker), and version control (Git).
- Excellent communication skills and the ability to collaborate effectively across teams.

Nice-to-Have Skills

- Direct experience building or interacting with Model Context Protocols (MCPs) or AI agents.
- Familiarity with CI/CD pipelines (like GitHub Actions) and automated deployments.
- Experience managing agile workflows in tools like Asana or Jira.
- Experience with Google Cloud Platform (GCP).
