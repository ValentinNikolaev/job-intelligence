# Software Developer (Go) - Security Analytics

Posted: 2026-09-06T09:30:23Z

## Rejection

- Category: location_requirement
- Reason: vacancy is explicitly non-remote

We are building a new capability that turns fragmented, noisy security logs into explainable, AI-powered threat analysis, delivered inside the RedMimicry platform.

As a Software Developer at RedMimicry, you will take a leading role in developing a new security analytics capability within our platform. You will build Go backend components and the application layer.

Experience with web frontend frameworks is welcome, but not required for this role.

This is a fixed term contract, running until 2027-10-31.

## Tasks

- **Build the Analysis Backend:** Implement the services that receive security telemetry, run analysis workflows, and store results and evidence.

- **Design APIs:** Define stable, versioned interfaces for ingestion, analysis, and reporting.

- **Design Domain Models:** Define maintainable data models for security events, analysis results, and supporting evidence.

- **Handle Long-Running Jobs:** Implement asynchronous processing, progress reporting, retries, cancellation, and useful failure states.

- **Work at Volume:** Move and process large telemetry sets with predictable memory, throughput, and backpressure behaviour.

- **Integrate Model Inference:** Build the interfaces between our services and our AI/ML components, including queuing, timeouts, partial results, and fallbacks.

- **Keep Evidence Traceable:** Preserve the path from an analysis result back to the exact source fields and log fragments behind it.

- **Implement Reporting:** Build consistent JSON and PDF reporting pipelines for machine-readable and human-readable outputs.

- **Build Secure Multi-Tenant Components:** Apply authentication, authorisation, tenant separation, and secure data-handling patterns.

- **Maintain Engineering Quality:** Add tests, review code, document interfaces, profile performance, and translate analyst feedback into concrete improvements.
