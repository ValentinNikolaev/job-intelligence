**Job description**

We are building modern, customer-facing software for the temp-staffing industry, integrating capabilities from multiple ERP systems and countries into reliable applications, workflows, services, and reusable platform components.

**We are looking for a product-minded senior fullstack engineer **who can turn ambiguous business requirements and complex existing systems into production-grade backend services, APIs, integrations, internal tools, and intuitive user interfaces.

TypeScript is central to our technology landscape. Experience with .NET and C# is strongly valued, while engineers with a background in strongly typed languages such as Java are also welcome. Comfort working across different stacks and languages is essential.

**AI and LLM tooling are central to how we work.** You should use AI-native workflows to explore faster, build in parallel, validate assumptions, and ship high-quality production solutions. You should care about correctness and maintainability, understand integration and business edge cases, choose simple and robust solutions, and own outcomes from exploration to production.

**Your tasks**

- **Fullstack Product Engineering:** Build customer-facing applications, backend services, APIs, internal tools, admin interfaces, automation, job runners, and configurable workflows
- **Backend & Domain Logic:** Design maintainable services, APIs, business logic, asynchronous processes, validation rules, and reusable components
- **Frontend Engineering:** Build intuitive and maintainable user interfaces using TypeScript and modern frontend frameworks
- **Integrations:** Connect applications with ERP systems, internal platforms, external APIs, databases, queues, files, and third-party services
- **Cloud & Production Ownership:** Deploy and operate reliable cloud solutions, preferably AWS, owning monitoring, alerts, failure handling, security, performance, cost, and operational reliability

**Your profile**

- Hands-on with Claude Code, Codex, and agent-based workflows; GitHub Copilot-style autocomplete alone is not enough
- Familiar with worktrees, subagents, MCP, structured prompts, harness engineering, parallelization, and validating AI-generated code and analysis to production quality
- Strong fullstack/backend experience, ideally with **.NET and TypeScript**
- Able to build production-grade services, APIs, scripts, tools, automation, and clean interfaces; comfortable with version control, review, debugging, testing, and existing systems
- Strong understanding of application architecture, API design, domain modeling, integration patterns, asynchronous processing, and maintainable software boundaries
- Comfortable with SQL, relational databases, schema design, transactions, migrations, indexing, and application-level data access
- Hands-on with AWS or similar cloud environments, including storage, databases, queues, containers, serverless/scheduled processing, SDKs, and APIs
- Understands deployment, secrets, networking, permissions, runtime configuration, scalability, performance, cost, and operational trade-offs
You may be a good fit if you are driven to improve how software is built, use AI and agent-based workflows to move faster, experiment with better approaches, and turn ambiguous problems into reliable production solutions. You should enjoy working across the stack, taking ownership beyond predefined tickets, improving existing systems, and rigorously validating AI-generated output rather than accepting it at face value. This role is less suitable for someone who prefers narrow responsibilities, fixed processes, or working within a single technical area without contributing to broader product and engineering outcomes.
