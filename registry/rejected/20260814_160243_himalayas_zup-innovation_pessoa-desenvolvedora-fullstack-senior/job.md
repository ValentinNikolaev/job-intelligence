### O que você fará por aqui

- Desenvolver aplicações web escaláveis utilizando Python no backend e Angular ou React no frontend.

- Projetar e implementar integrações de APIs RESTful, garantindo segurança e performance.

- Revisar código de colegas, propor refatorações e garantir padrões de qualidade em colaboração com o time.

- Configurar, automatizar e monitorar pipelines CI/CD em ambientes cloud AWS.

- Implementar estratégias avançadas de caching e resolução de problemas complexos nos processos de build frontend.

- Atuar como referência técnica em discussões sobre arquitetura de microfrontends e integração de módulos.

### O que esperamos que você saiba

- Domínio em Python para desenvolvimento backend.

- Experiência avançada com Angular e React para interfaces frontend.

- Capacidade de implementar e versionar APIs RESTful seguras.

- Sólido conhecimento em AWS (S3, CloudFront) para exposição de frontends e automação via Infraestrutura como Código.

- Habilidade avançada em configuração de ferramentas de build (Webpack, Rollup) e estratégias de caching.

- Vivência com arquitetura de Microfrontends e integração entre módulos independentes
