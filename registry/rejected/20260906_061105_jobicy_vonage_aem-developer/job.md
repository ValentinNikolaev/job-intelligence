### **Join Vonage and help us innovate cloud communications for businesses worldwide!**

### **Why this role matters:**

We are seeking an experienced and technically skilled Senior AEM Developer to join our digital engineering team. In this role, you will lead the design, development, and implementation of enterprise-level web applications using Adobe Experience Manager (AEM / AEM as a Cloud Service). You will collaborate closely with product owners, UI/UX designers, and front-end developers to deliver high-performing, scalable, and secure digital experiences.

### **Your key responsibilities:**

-

Technical Design & Development: Design and develop custom AEM components, templates, dialogs, schedulers, workflows, and OSGi services using Java, HTL/Sightly, and Sling Models.

-

Architecture & Implementation: Build robust multi-site, multi-lingual, and multi-channel publishing solutions leveraging AEM WCM, DAM (Digital Asset Management), and MSM (Multi-Site Manager).

-

Cloud & Modernization: Guide migration efforts and work extensively with AEM as a Cloud Service, Dispatcher configurations, and modern deployment pipelines.

-

Integrations: Integrate AEM with third-party systems and enterprise services, including CRM, analytics (Adobe Analytics/Target), and headless content APIs.

-

Code Quality & Mentorship: Conduct rigorous code reviews, enforce best practices in software development (TDD, CI/CD), and mentor junior-to-mid-level developers.

-

Performance Optimization: Troubleshoot and optimize application performance, caching strategies (Dispatcher cache flush), and security compliance.

-

AI : Demonstrate the usage of AI Agents and code assistants to improve the productivity across the software development lifecycle, by reducing boilerplate coding, automating repetitive tasks, accelerating code reviews, and reducing time-to-market for new features.

-

Agile Delivery: Participate actively in Agile/Scrum ceremonies, translating business requirements into technical execution plans and accurate estimates.

### What you'll bring

**Required:**

**Experience:**

- 5+ years of total software development experience.

- 3+ to 5+ years of hands-on technical experience specifically with **Adobe Experience Manager (AEM 6.x and AEM as a Cloud Service)**.

**Core AEM Expertise:**

- Deep understanding of the underlying AEM framework, including Apache Sling, Apache Felix (OSGi), JCR (Java Content Repository), and CRX.

- Proficiency in building Touch UI components using Granite UI, HTL (HTML Template Language), and Sling Models.

- Experience configuring Dispatchers, replication agents, and cloud manager pipelines.

**Backend & Frontend Technologies:**

- Advanced proficiency in **Core Java / J2EE**, web services (REST) and enterprise design patterns.

- Solid front-end foundation: HTML5, CSS3, modern JavaScript (ES6+), SCSS, Tailwind CSS, and responsive design frameworks (e.g., Bootstrap, React, or Vue).

**DevOps & Tooling:**

- Experience with build automation and version control tools: Maven, Webpack, Babel, Git, Jenkins, and Adobe Cloud Manager.

- Familiarity with unit testing frameworks (JUnit, Mockito).

**Methodologies:**

- Strong background working in Agile/Scrum development environments.

- Excellent problem-solving skills with the ability to articulate complex technical concepts to non-technical stakeholders.

**Experience we consider a plus:**

- Adobe-certified expert credentials (e.g., Adobe Certified Expert – AEM Sites Developer).

- Experience with headless content delivery (AEM Content Services / GraphQL).

- Hands-on exposure to Adobe Experience Cloud ecosystem tools (Adobe Target, Adobe Analytics, Adobe Campaign).
