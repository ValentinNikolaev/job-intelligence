# Back End Engineer

Posted: 2026-08-11

## Rejection

- Category: tech_stack
- Reason: role does not mention Go/Golang or PHP

Ми шукаємо **Backend Engineer**, який має досвід роботи на стику **low-latency backend, real-time data processing та HFT**.

У пріоритеті інженери, які володіють **Go**. Також розглядаємо кандидатів із досвідом у **C/C++/Rust.** Необхідний досвід ручного керування пам’яттю, алокаціями, GC та профілювання.

Компанія працює на реакції ринку на новини — збирає події із зовнішнього світу, аналізує їхній вплив на ринок і угоди, тобто де важливо першими дізнатися про новину та першими відреагувати, щоб максимізувати прибуток. **Боротьба за мілісекунди**.

Необхідно глибоке розуміння протоколів, принципів роботи та особливостей інтернет-інфраструктури, розуміння того, як влаштована мова програмування зсередини та як вона керує пам’яттю.

Також важливо мати досвід роботи з **API криптобірж**, розуміти, як ефективно конкурувати в **HFT-стратегіях (порядку 0,5–5 мс)**, розуміти, як працюють різні типи ордерів, як влаштовані ф’ючерси та маржинальне кредитування, що таке colo та Avelacom.

Необхідно навички **низьколатентного парсингу (250 мс****і менше від моменту публікації),** розуміння проблем кешу, способів його обходу та подолання rate limits.

**Очікування:**

- **6+ років комерційної розробки**, з **яких 2+ роки в HFT**

- ТА в одному з напрямів: trading systems / брокери, RTB / adtech, CDN / edge, real-time gaming / netcode, WebRTC / VoIP / streaming, або інші high-load / low-latency системи
- АБО **4+ роки досвіду у створенні високошвидкісних парсерів**.

- Ми розглядаємо кандидатів, які вміють ефективно застосовувати **ШІ**. Також розглядаємо кандидатів, які почали працювати ще до появи перших ШІ, здатних писати код.

**Стек:**

- Мова: Go — основна
- Хмара: AWS, кілька регіонів (Токіо, Сінгапур, Сеул), окремі VPS
- Сховища: Redis (control plane, streams, pub/sub), PostgreSQL, ClickHouse
- Транспорт сигналу: shared memory IPC, UDP, WebSocket
- Збір даних: REST/WS API криптобірж, резидентські проксі-пули, vendor push-фіди, TLS-фінгерпринтинг
- Торгова частина: REST і WebSocket order entry на кількох біржах, власний шар підпису та лімітів
- Спостережуваність: Prometheus, Grafana, Loki
- Запуск: PM2, systemd, Docker. Kubernetes не використовується

**Компанія пропонує:**

- Роботу над системами, де **мілісекунди реально мають значення**.
- Роботу з low-latency, networking, real-time data та trading infrastructure.
- Сильну інженерну команду та задачі, які цікаво розв’язувати на Senior-рівні.
- Компенсацію обговорюємо індивідуально відповідно до кожного залучено проекту.
- Формат: попроєктна співпраця
- Зайнятість: part-time / full-time

**Співбесіда:**

- Технічна розмова — уточнюючі питання щодо досвіду та підходів.
- Ознайомчий дзвінок.
