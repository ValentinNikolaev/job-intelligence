Want to work in the fintech industry, using the latest technologies and tools to help deliver online cloud and container based applications for a new breed of payment services?

We are searching for Data Engineer, who will be responsible for transferring business requirements into technical requirements of the AEVI data architecture based on AWS technology.

**What you'll be doing:**

- Translate business requirements into technical specifications for AEVI’s AWS-based data architecture

- Work with technologies such as Aurora, Oracle, Athena, Glue, and QuickSight

- Manage and optimize Data Warehouses & Data Lakes

- Design, configure, and administer data architecture in compliance with PCI, GDPR, and CCPA

- Document data flows and implement data models within business applications

- Ensure cloud data management meets CIA (Confidentiality, Integrity, Availability) standards

- Redesign data models to maintain regulatory compliance

- Develop and manage a structured data access model

**The successful AEVI'ator: Data Engineer**

- Strong expertise in SQL, DML, and DDL

- Excellent communication skills at both business and technical levels

- Deep knowledge of AWS Cloud Data technologies

- Proficiency in streaming platforms (Kafka, AWS Kinesis) for real-time data processing

- Experience with big data frameworks (Apache Spark, Hadoop)

- Familiarity with infrastructure-as-code tools (Terraform, AWS CloudFormation)

- Solid knowledge of Python and Java

- Strong data modeling and design skills

- Proficiency in AWS database services

- Good understanding of data classification, encryption, and privacy
