## Rejection

**Your responsibilities will include**

- Analysis of multiomics data (e.g., NGS, transcriptomics, metabolomics) in oncology / inflammation
- Support non-clinical / clinical development in all phases, analysis plan (e.g. SAP), reporting
- Implementation and reporting of exploratory biomarker analyses
- Serving clients with ad-hoc data analysis requests and statistical consulting
- Following quality and documentation standards in a GxP environment
- Supporting the bioinformatics/statistics team, as well as independent work in diverse and exciting projects

**Your profile**

- Master’s degree / PhD in bioinformatics, computer science, or equivalent education
- Experience in analysing multiomics and biomarker data (e.g., NGS data including transcriptomics); gene set analysis and clustering is a plus
- Experience in setting up / executing bioinformatics pipelines using e.g. Nextflow, containerisation
- Solid knowledge and understanding of statistical concepts e.g. hypothesis testing, survival analysis, linear models, as well as experience in the application of advanced statistics visualizing, exploring and modeling multivariate data sets
- Very good programming skills in R / Bioconductor; Shell-scripting and Git is a plus
- Good overview of state-of-the-art bioinformatics tools and proven record of the ability to collect, combine and analyse complex types of data
- Fast comprehension, analytical thinking, teamwork and a high degree of initiative, willingness to learn
- Creativity and joy in solving complex analytical questions and proactive working style
- Very good English skills, German is an advantage
