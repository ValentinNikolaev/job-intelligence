### Build the Core System Behind a Large-Scale Telecommunications Network

We are looking for an experienced **Middle Full Stack PHP Developer** to join our engineering team and contribute to the development of a mission-critical telecommunications platform.

This solution serves as the central source of truth for network inventory and configuration management, enabling engineers to efficiently manage telecom infrastructure, equipment, network topology, and customer service dependencies. The platform stores and processes large volumes of data while supporting complex business processes essential for the operation of a modern telecom network.

If you enjoy solving complex backend challenges, working with high-performance databases, and gradually modernising legacy applications with contemporary technologies, we’d love to hear from you.

### What You’ll Do

- Design, develop, and maintain backend functionality using **PHP 8.4**.
- Build clean, maintainable, and scalable application architecture following modern software engineering principles.
- Develop and optimise complex SQL queries for **Oracle Database**, working with datasets containing millions of records.
- Analyse, maintain, and gradually refactor legacy frontend components built with **ExtJS**.
- Participate in the migration of the frontend to **Vue.js** using modern JavaScript (ES6+).
- Collaborate with teammates to improve system performance, stability, and code quality.
- Work with Git for version control and perform basic administration tasks in Linux and Windows Server environments.

### What We’re Looking For

### Backend

- Strong commercial experience with **PHP 8.4** and deep understanding of native PHP development.
- Solid knowledge of **Object-Oriented Programming (OOP)** and software design principles.
- Practical experience applying **MVC, SOLID, DRY, and KISS** principles.
- Strong SQL skills and hands-on experience with **Oracle Database**.
- Experience optimising complex queries and working with high-volume databases.

### Frontend

- Basic experience with **ExtJS 3.x** for reading, maintaining, and refactoring legacy code.
- Experience with **Vue.js** and modern JavaScript (ES6+) for developing new frontend functionality.
- Working knowledge of **HTML, CSS, and jQuery**.

### Tools & Environment

- Experience using **Git**.
- Basic Linux administration skills (SSH, configuration files, command line).
- Familiarity with **Oracle Linux** and **Windows Server** environments.

### About the Project

You’ll be working on an enterprise-grade **Network Inventory & Configuration Management System** used to manage the infrastructure of a telecommunications network.

The platform maintains detailed information about installed network equipment—including systems, modules, interface cards, ports, cables, and other infrastructure components—as well as network topology, configured connections, and the customer services that rely on them. The system plays a critical role in ensuring the accuracy, reliability, and scalability of telecom operations.

### Why Join Us?

- Work on a large-scale, business-critical telecommunications platform.
- Solve technically challenging problems involving complex business logic and high-volume data processing.
- Modernise legacy solutions by introducing contemporary technologies such as **Vue.js**.
- Collaborate with an experienced engineering team in a stable, long-term project.
- Make a direct impact on the evolution of a platform that supports essential telecom infrastructure.
