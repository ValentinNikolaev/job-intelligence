### About Tone Singleton

Tone Singleton is a technology company building software products across multiple domains, from CRM systems for healthcare clients to mobile learning applications for Mandarin Chinese learners. We operate as a lean engineering team that owns its infrastructure end-to-end, from AWS CDK stacks to end-user interfaces.

### The Role

We’re looking for a versatile full-stack engineer to join our small team (currently 3 developers). You’ll work across the entire product lifecycle: designing data models, building backend services, crafting frontends, configuring CI/CD, managing infrastructure, and shipping features to production. This isn’t a role where you write React components all day — you’ll set up Docker containers one morning and design a Microsoft Graph API integration the next.

### What You’ll Work On

- **CRM systems**: Vendor and custom, with extensions (PHP/TypeScript).
- **Websites**: Next.js + Tailwind CSS deployed on AWS Amplify. Payload CMS for content management. Storybook for component documentation. SEO and analytics.
- **Mobile applications**: React Native apps. SQLite-based offline-first architecture with Drizzle ORM. iOS deployment via Fastlane.
- **Developer tooling**: Projen-based project scaffolding library that generates standardised TypeScript packages, CDK constructs, Next.js apps, Payload CMS setups, and React Native projects.
- **Infrastructure**: AWS CDK v2 stacks managing multi-account environments, Aurora Serverless PostgreSQL, CloudFront CDN, Route 53, SES email, and Amplify deployments. On-premise VM management with ESXi, Docker, NGINX (SWAG), and Portainer.

### Day-to-Day Responsibilities

- Design and implement features end-to-end (API → database → UI)
- Set up and maintain CI/CD pipelines (GitHub Actions)
- Configure production environments including Docker containers, DNS records, and SSL
- Write and review pull requests in a trunk-based development workflow (feature branches → develop → main)
- Manage dependency updates and security patches
- Troubleshoot production issues (connection failures, container lifecycle, build performance)
- Build reusable libraries and abstractions (ORM clients, type packages, CDK constructs)

### Must-Have

- Strong TypeScript proficiency across Node.js and browser/React environments
- Experience with Next.js (App Router, server components, middleware)
- Comfortable with Docker, Linux server administration, and networking fundamentals (DNS, reverse proxies, SSL)
- AWS experience — at minimum: Amplify, S3, CloudFront, RDS/Aurora, SES. CDK knowledge is a strong plus.
- GitHub Actions CI/CD pipeline authoring
- Ability to work independently, create well-scoped issues, and drive features to completion without hand-holding
- Conventional commits and clean PR hygiene

### Nice-to-Have

- React Native / mobile development experience
- PHP experience
- Microsoft Azure AD / Graph API / SCIM integration experience
- Projen or jsii experience
- Payload CMS or similar headless CMS experience
- Familiarity with Storybook for component-driven development
- AWS CDK v2 with multi-account, multi-environment patterns
- SQLite / Drizzle ORM experience
- VMware ESXi / on-premise infrastructure management

### What We Value

- **Ownership** — you create the issue, implement the feature, deploy it, and verify it works in production.
- **Perfectionism** — we don’t consider it to be a flaw and prefer slower but better.
- **Breadth** — the team is small. You’ll touch PHP, TypeScript, Python, Docker, AWS, NGINX, and more within any given month. Yes, unfortunately this means occasional context-switching that we’re trying to minimise as much as possible.
- **Clear communication** — issues are well-described with context. PRs have descriptive titles. Questions get asked early, not after a week of going in the wrong direction.

### How We Work

- Small team (you + 3 engineers), flat hierarchy
- GitHub-centric: issues with milestones, project boards, typed issues (Bug/Task), Dependabot for automated updates
- Projen manages project configuration — no manual package.json edits
- Conventional commits enforced via Husky/commitlint
- We use AI-assisted development tooling (Kiro) and are building autonomous agent infrastructure (Bedrock AgentCore)
- You’ll be given a monthly AI tokens allowance
- You’ll be given a paid AWS SkillBuilder subscription and your AWS certification exams expenses will be covered
