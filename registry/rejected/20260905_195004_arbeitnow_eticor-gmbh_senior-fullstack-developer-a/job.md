### **Die Prämisse: Code ist kein Asset, Code ist Liability.**

Wir suchen keinen Entwickler, der stolz auf die Anzahl seiner geschriebenen Zeilen ist. Wir suchen einen Architekten, der versteht, dass **Vibe Coding** (nach Karpathy u.a.) die Abstraktionsebene fundamental verschoben hat. Deine Arbeitseinheit ist nicht mehr die Funktion, sondern der **Agentic Workflow**.

In unserem Legal-Compliance-Umfeld ist Qualität nicht verhandelbar. Deine Aufgabe ist es, probabilistische Coding-Agents (LLMs) so zu orchestrieren, dass sie deterministische, auditsichere Software für .NET und React liefern.
