# Sr Enterprise Full Stack Developer

Posted: 2026-08-03T19:18:16Z

## Rejection

- Category: tech_stack
- Reason: role does not mention Go/Golang or PHP

We are searching for a **Senior .NET Developer** on behalf of one of our clients, a successful and growing property & casualty insurance software company. The client develops proprietary enterprise solutions that manage the full operational suite for insurance carriers, their agents, and customers. This is an exciting opportunity to work with both established and cutting-edge Microsoft-based technologies, including an active migration to .NET Core and integration of AI tools into real development workflows.

### Responsibilities

- Design, develop, and maintain full-stack features across backend services, APIs, frontend, and database layers

- Work primarily on backend systems (~80%) with some frontend responsibilities (~20%)

- Contribute to and modernize legacy VB.NET MVC applications while supporting the migration to .NET Core

- Build and integrate AI-assisted development workflows using tools such as ChatGPT, Claude, or similar technologies

- Collaborate directly with clients to gather requirements, deliver enhancements, and provide technical solutions

- Write and optimize SQL queries, stored procedures, and database interactions in SQL Server

- Participate in Agile development processes using tools like JIRA and Git/TFS

### Requirements

- 7–8+ years of full-stack development experience, with the ability to independently own features end-to-end

- Strong hands-on experience with VB.NET and C#

- Solid command of ASP.NET MVC architecture — controllers, backend integration, and request lifecycle

- Proficiency in JavaScript, jQuery, and Bootstrap

- Strong SQL Server and T-SQL skills, including stored procedures and query optimization

- Experience with TFS and Visual Studio 2019+

- 1–2+ years of hands-on experience using AI tools in a real development workflow (ChatGPT, Claude, OpenWebUI, or similar)

- Proven ability to work directly with clients, gathering requirements and translating them into technical solutions

- Self-directed, mature, and comfortable working with minimal supervision

- Familiarity with Agile methodologies and tools like JIRA

### Nice to Haves

- Experience migrating legacy applications to .NET Core

- Familiarity with cloud environments, particularly Azure

- Exposure to agentic coding workflows, MCP servers, or prompt engineering for production use cases

- Familiarity with infrastructure such as Windows Server, Hyper-V, or on-premise data centers

- Prior experience in enterprise software development, ideally within insurance or financial systems

If you are a seasoned .NET developer who thrives in a client-facing, hands-on role and wants to work at the intersection of legacy modernization and emerging AI technologies, we'd love to hear from you.
