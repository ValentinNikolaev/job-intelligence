### About the Role

This is a high-ownership engineering role at a fast-growing, open-source AI engineering platform — think of it as the Datadog for LLM observability. The platform is trusted by thousands of development teams worldwide, and the SDKs you'll own are downloaded **millions of times each month**, often serving as the very first touchpoint a developer has with the product.

The SDKs run in production environments ranging from serverless functions to long-running agent loops. They must be rock-solid: minimal CPU and memory overhead, zero tolerance for failure, and a developer experience that feels effortless. When you ship, thousands of developers benefit the same day.

### What You'll Do

-

**Own the Python and TypeScript SDKs end-to-end** — reliability, performance, and developer experience. Set the bar for SDK quality across the organization.

-

**Design APIs developers love** — naming conventions, parameter structure, breaking-change communication, and documentation. Every detail of the DX is yours to shape.

-

**Drive OpenTelemetry-based integrations** — architect and implement framework integrations across the AI/LLM ecosystem (e.g. major LLM providers, orchestration frameworks, agent runtimes).

-

**Maintain and evolve the SDK release lifecycle** — versioning strategy, packaging, CI/CD pipelines, compatibility testing, and automated release management.

-

**Performance engineer the SDK** — profile, identify bottlenecks, and reduce latency and memory footprint so the SDK is never the limiting factor in production.

-

**Engage the open-source community** — triage GitHub issues, review external PRs, write developer-facing docs, and represent the project on public channels.

-

**Collaborate cross-functionally** — work closely with product and data teams to translate platform capabilities into clean SDK abstractions.
