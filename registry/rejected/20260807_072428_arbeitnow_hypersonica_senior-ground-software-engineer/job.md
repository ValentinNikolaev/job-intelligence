**What you'll do**

-

Design and develop ground software used for mission preparation, execution, and monitoring of hypersonic systems.

-

Build robust, user facing applications for Linux and Windows environments that support operators and engineers during real missions.

-

Implement high performance C++ software with a focus on reliability, usability, and maintainability.

-

Develop intuitive user interfaces and workflows to visualise system state, mission data, and operational status.

-

Integrate ground software with simulation, test, and live system interfaces to support end to end operations.

-

Work closely with systems, GNC, test, and operations teams to translate mission needs into effective software tools.

-

Where useful, leverage UI frameworks (e.g. Qt) and mapping or visualisation SDKs to accelerate development.

**Who you are**

-

A Senior software engineer with 5+ years’ experience building ground or operator-facing software in aerospace, defence, or complex technical domains.

-

Comfortable developing user-facing applications on Linux and Windows, with an understanding of operational reliability.

-

Fluent in modern C++, with an instinct for performance, robustness, and clean architecture.

-

Someone who cares deeply about operator experience, clarity, and usability in high-pressure environments.

-

Experienced translating mission and system needs into practical software tools, not just features.

-

Pragmatic about tooling, with exposure to UI frameworks such as Qt and an interest in visualisation or mapping technologies.

-

Able to move quickly in a startup environment, balancing polish with delivery speed.

-

Motivated by building software that operators trust during real missions, not demo-only systems.
