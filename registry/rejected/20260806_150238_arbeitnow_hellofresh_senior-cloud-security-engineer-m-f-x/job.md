- **Remediate **and validate security issues across cloud infrastructure

## **What you’ll bring**

- Detailed understanding of cloud and network security, modern threats and security best practices

- Fluency in one or more programming or scripting languages

- Ability to work independently and as part of cross-functional squads

- Knowledge of security engineering, computer and network security, security protocols, and applied cryptography
