### About the Role

This is a high-ownership engineering role at a fast-growing, open-source AI engineering platform — think of it as the observability layer for LLM applications and agents. The platform is widely adopted across enterprises and the developer community, with tens of millions of monthly SDK downloads.

As a **Senior Product Engineer**, you own features completely: from the initial user call to the shipped code, docs, and public changelog post. No handoffs. Recent examples of single-engineer-owned releases include a full agents observability release, a TypeScript SDK rewrite on OpenTelemetry, and a hosted MCP server for prompt management — that's the scope and autonomy on offer here.

### What You'll Do

-

**Own features end-to-end** — conduct user calls, write specs, ship code, write documentation, and publish the changelog post under your name.

-

**Work the full stack** — React frontend, Next.js backend, ClickHouse analytics, Python and TypeScript SDKs. You touch whatever the feature needs.

-

**Build and maintain open-source SDKs and client libraries** — contributing to a public, community-visible codebase with high engineering standards.

-

**Instrument and monitor production LLM systems** — collecting and analyzing metrics such as latency, cost, and quality across AI application pipelines.

-

**Collaborate cross-functionally** — work directly with product managers and designers, and engage with the open-source community through public code reviews and documentation.

-

**Shape product direction** — bring user insights directly into prioritization and feature design.
