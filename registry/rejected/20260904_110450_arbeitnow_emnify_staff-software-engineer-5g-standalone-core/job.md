Your Role

As part of the larger Engineering department, the Core Network team builds and operates the heart of emnify's SuperNetwork — the mobile core that keeps millions of IoT devices connected across 180+ countries. As we evolve our platform towards a cloud-native **5G Standalone (SA)** core, we're looking for a hands-on 5G SA expert to help us design, build, and run it.

As a Staff engineer with deep 5G SA expertise, you'll take technical ownership of the core network functions and roaming scenarios that make global IoT connectivity work. You'll set the technical direction for our 5G SA core while staying hands-on — designing, implementing, testing, and troubleshooting the software components that run in production at scale. You'll partner closely with engineers across squads, share your expertise, and raise the bar for how we build cloud-native telecommunications software.

This is a hybrid position based at emnify’s Berlin office.

Your Impact

-

You'll architect, design and build using AI-agentic workflows software components for emnify’s cloud native 5G Standalone core in C++, Go, or Java — implementing and operating network functions (NFs) and the service-based interfaces between them and integrating into the overall emnify platform OSS and BSS.

-

You'll own 5G roaming scenarios end-to-end, designing and implementing the signaling and interworking that keep IoT devices connected as they move across networks and borders.

-

You'll help deploy and operate the 5G core at scale on AWS and Kubernetes, building for high availability, observability, and performance across regions.

-

You'll set technical direction and raise engineering standards across teams — mentoring engineers, reviewing designs, and driving decisions on protocols, network functions, and core architecture.

-

You'll troubleshoot complex, live telecommunications issues across the stack, from core network protocols down to the running service.

What we expect

-

Deep, hands-on expertise with the **5G Standalone core**: core specifications and core signalling protocols (e.g. service-based interfaces over HTTP/2, Diameter, GTP-C/U), roaming scenarios, core network protocols, and network functions (NFs). Our focus is the mobile core network domain; hands-on experience with 5G RAN technologies is not a requirement for this role.

-

Experience with cloud-native networking, service mesh, and observability for high-throughput distributed systems.

-

**Hands-on software engineering is essential.** You can architect/design, implement, test, and troubleshoot software components using AI-agentic workflows.

-

Strong software development experience in at least one of **C++, Go, or Java** combined with a results-oriented mindset and readiness to work across the technology stack when needed.

-

Experience with large-scale infrastructure deployment and orchestration (**AWS, Kubernetes**).

-

Proven experience running **telecommunications services at scale** in production.

**Bonus points:**

-

Background in IoT/M2M connectivity or MVNO/MNO core network operations.
