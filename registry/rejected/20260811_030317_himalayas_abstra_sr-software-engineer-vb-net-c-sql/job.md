### Job Description

We’re on the lookout for a Senior VB.NET Software Engineer with strong expertise in Microsoft technologies to join our team.

As a Senior VB.NET Software Engineer, you will be part of a high-performing team responsible for maintaining, enhancing, and supporting enterprise applications built primarily with VB.NET and Windows Forms. This role requires a strong passion for software development, problem-solving, and continuous improvement. You will work on modernizing and extending legacy applications while ensuring stability, performance, and maintainability across multiple systems.

While the primary focus is VB.NET development, familiarity with C#, SQL Server, and REST APIs is important, as the team also supports satellite applications and integration services built with these technologies. As a senior member of the Scrum team, you will contribute to technical decisions, uphold coding standards and best practices, and collaborate closely with stakeholders to deliver high-quality software solutions.

Location: LATAM 100% Remote. Working hours are based on the US Central Time Zone.

- Provide technical guidance and knowledge sharing within the team.
