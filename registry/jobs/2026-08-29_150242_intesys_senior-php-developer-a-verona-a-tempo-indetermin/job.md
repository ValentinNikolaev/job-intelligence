Senior PHP Developer

Stiamo cercando un
Senior PHP Developer
, laureato in Informatica o Ingegneria Informatica con
4-5 anni di esperienza in ruolo analogo
e con la voglia di mettersi in gioco ed affrontare nuove sfide.

La figura contribuirà allo
sviluppo di progetti web
come siti, landing page e gestionali e nell’
integrazione tra sistemi
che interagiscono con il sito web di riferimento.

La persona che cerchiamo sarà chiamata a diventare un
punto di riferimento per i nostri progetti di comunicazione
, dimostrando autonomia nella gestione di progetti e ottime capacità relazionali.

HARD SKILLS

Ecco le competenze tecniche e professionali per noi fondamentali

Ottima conoscenza di PHP;

Ottima conoscenza di HTML, CSS, JavaScript e tecnologia AJAX;

Buona conoscenza del Framework PHP Laravel;

Buona conoscenza di PostgreSQL e MySQL;

Buona conoscenza dei sistemi di controllo di versione del software in particolare GIT;

Progettazione di database relazionali e buona conoscenza del linguaggio SQL.

Nice to have
:

Familiarità con metodologia DevOps;

Conoscenza di framework frontend (React, Vue);

Progettazione e sviluppo di API e microservizi;

Conoscenza ambiente server Linux e configurazioni Apache, PHP-FPM, Database relazionali (stack Lamp);

Conoscenza di ambienti di virtualizzazione focalizzati agli ambienti di sviluppo;

Conoscenza di architetture a container quali Docker e/o Kubernetes;

Conoscenza DNS per configurazione/gestione di domini.
