# Full-stack Software Engineer (NXJ-192)

Posted: 2026-08-06

### The Role

You will own end-to-end features for the Global Card platform—from customer-facing interfaces to core banking services handling card issuance, balances, and multi-geography money movement. The technical challenge lies in delivering consumer-grade responsiveness while maintaining the zero-tolerance correctness and security required of a regulated financial product. AI-assisted engineering and agentic coding tools are deeply embedded into the daily delivery workflow here, not treated as an experimental side project.

### About the Product

The product is a multi-currency Global Card and digital wallet infrastructure designed to let users hold, spend, and transfer funds seamlessly across global jurisdictions. It integrates directly with payment networks, ledger systems, and regulatory compliance engines to process real-time financial transactions. The platform operates under high-availability and low-latency requirements to ensure secure, instant settlement for international users.

**Technology Stack: **The frontend is built on React and TypeScript, connected via GraphQL to high-throughput backend services written in Go and Node.js. The infrastructure is fully cloud-native, running microservices across distributed cloud environments (AWS/GCP) designed for elastic scale and strong fault tolerance. The development cycle actively leverages agentic AI tooling for spec drafting, prototyping, and code generation.

### What You’ll Be Doing

- Own the architectural design and end-to-end implementation of global card issuance and real-time transaction pipelines
- Build resilient GraphQL and REST APIs connecting frontend surfaces with core ledger and money-movement services
- Integrate agentic coding workflows into daily development to accelerate prototyping, code generation, and technical spec creation
- Eliminate failure points in critical payment paths to ensure fault tolerance and regulatory compliance across target geographies
- Drive technical design and data modeling for next-generation lending and digital wallet capabilities
- Partner with cross-functional peers in Product and Data Science to translate multi-currency financial workflows into production code
