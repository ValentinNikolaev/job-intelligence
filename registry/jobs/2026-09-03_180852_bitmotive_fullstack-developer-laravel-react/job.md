# Fullstack Developer (Laravel + React)

Posted: 2026-09-02

### The stack, and why we are not strict about it

Our largest engagement is a Laravel API with a Filament admin and a React Native client. Others run on Python and on TypeScript with React. New engagements arrive with the stack already chosen, by the client or by whoever built the first version, and you do not get to pick which one you land on.

So the language on your CV matters less to us than whether you can be dropped into a codebase you did not write and be useful in it within a couple of weeks. We would rather hire someone with deep PHP and workable TypeScript who has done that twice than someone who has only ever worked in one framework.

### How we work

Every change starts as a written specification with acceptance criteria. A person reviews the charter, the plan, and the demo. Tests are written first and ship with the change, not after it. CI stays green on main.

If a specification is ambiguous, we expect you to say so before you implement it, and that counts as doing the job correctly, not as blocking the work.

### What you will do

- Implement product features against approved specifications on live client engagements.
- Write and maintain the automated tests that go with each change, as part of finishing it.
- Review other engineers’ changes against the specification and the project’s own rules.
- Move between engagements and stacks as work demands, without a long ramp each time.
- Work directly with US product leadership on requirements and demos. Nobody translates for you.

### What we need

- 3+ years building and shipping production web applications.
- Real depth in at least one server-side language. **PHP with Laravel is the most useful to us today.** Python and Node also count.
- Working competence in a second language or framework, and at least one time you picked up a codebase in something you had not shipped in before. We will ask you about that specifically.
- TypeScript and React on the front end.
- Relational database design and the ability to work out why a query is slow.
- AWS.
- Test discipline. You should be able to describe how you decide what to test and what you deliberately leave untested.
- English at **B2 or above**, written and spoken. You will be on calls with US clients and the US team directly. This is a functional requirement of the role.

### Useful, not required

- Filament, Livewire, or a comparable admin layer over Laravel.
- React Native and Expo. There is mobile work, but it is not the whole job.
- Healthcare or other regulated software: HIPAA, IEC 62304, ISO 13485, or comparable.
- Next.js, Drizzle or a similar typed ORM.
- Working alongside AI coding tools inside a reviewed process rather than ad hoc.

### Employment

- **Location:** Remote from Ukraine or Poland
- **Employment type:** B2B or employment contract, confirmed at offer
- **Compensation:** Based on the candidate’s level and discussed during the first call.
