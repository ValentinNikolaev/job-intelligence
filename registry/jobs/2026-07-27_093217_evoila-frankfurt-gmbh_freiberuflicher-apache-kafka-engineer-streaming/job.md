# Freiberuflicher Apache Kafka Engineer / Streaming-Spezialist (m/w/d)

Posted: 2026-07-27T07:31:00Z

Für ein Kundenprojekt suchen wir einen **freiberuflichen** **Apache Kafka Engineer / Streaming-Spezialist** **(m/w/d).** Die Tätigkeit erfolgt überwiegend remote, mit gelegentlichen Einsätzen vor Ort beim Kunden.

## Aufgaben

- Design, Aufbau und Betrieb von Kafka-Clustern (Self-Managed und/oder Confluent Cloud / MSK)

- Konzeption und Implementierung von Event-Streaming- und Event-Driven-Architekturen

- Entwicklung und Optimierung von Producern, Consumern und Stream-Processing-Pipelines (Kafka Streams / ksqlDB / Flink)

- Anbindung von Quell- und Zielsystemen über Kafka Connect (Source-/Sink-Connectoren)

- Sicherstellung von Performance, Skalierbarkeit, Hochverfügbarkeit und Fehlertoleranz

- Monitoring, Alerting und Troubleshooting (z. B. Prometheus, Grafana, Confluent Control Center)

- Etablierung von Best Practices für Topic-Design, Partitionierung, Schema-Management und Data Governance

- Wissenstransfer und Enablement des internen Teams

## Qualifikation

- Mehrjährige, nachweisbare Erfahrung mit Apache Kafka in Produktivumgebungen

- Tiefes Verständnis der Kafka-Internals (Broker, Partitions, Replikation, Consumer Groups, Offsets, ISR)

- Praxis mit Kafka Connect und dem Confluent-Ökosystem

- Erfahrung mit Stream Processing (Kafka Streams, ksqlDB oder Apache Flink)

- Schema-Management mit Schema Registry (Avro / Protobuf / JSON Schema)

- Fundierte Programmierkenntnisse (Java, Scala und/oder Python)

- Erfahrung mit Cloud-Plattformen (AWS MSK, Confluent Cloud, Azure Event Hubs o. ä.)

**Darüber hinaus verfügst du idealerweise über:**

- Confluent-Zertifizierung (CCDAK / CCAAK)

- Erfahrung mit Kubernetes und Containerisierung (z. B. Strimzi Operator)

- Kenntnisse in Infrastructure as Code (Terraform, Ansible)

- Security-Erfahrung (mTLS, SASL, ACLs, RBAC)

- Erfahrung in Projekten innerhalb der Transport- und Logistikbranche
