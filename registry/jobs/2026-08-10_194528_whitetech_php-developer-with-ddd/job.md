# PHP Developer with DDD

WhiteTech is hiring a remote PHP Developer with DDD to build and improve secure,
well-tested, high-performing payment products. The company welcomes candidates
across Europe and also considers other locations when the candidate can work in
Central European Time (CET).

Responsibilities:
- Design, develop, test, document, release, and support software from scratch.
- Enhance existing APIs and backend systems.
- Integrate acquirers, gateways, alternative payment methods, token platforms,
  customer verification/scoring/monitoring systems, reporting, and other
  third-party payment solutions.
- Create and run tests and set up test environments for new features.
- Debug software and fix existing defects.
- Prepare technical documentation and support software in production.
- Collaborate with frontend developers and other team members.

Qualifications and technical expectations:
- PHP performance optimization, caching, asynchronous processing, and experience
  supporting large-scale projects.
- OOP and deep Symfony expertise, including RESTful APIs and Doctrine ORM.
- PostgreSQL, complex SQL performance optimization, indexes, execution plans,
  normalization, entity-relationship modeling, and database schema design.
- Docker and Kubernetes internals; Docker Engine, Docker Hub, and Docker Swarm.
- SOLID, GRASP, design patterns, and architectural patterns.
- Advanced DDD: Domain Events, Domain Services, Bounded Contexts, and complex
  domain modeling.
- CQRS, including asynchronous command processing and synchronization of read and
  write models.
- Architecture design for complex, large, scalable systems and documentation of
  architectural decisions.
- Advanced PHP integration testing with PHPUnit, Codeception, or Behat, including
  test-environment setup and dependency management.
- Event Sourcing architecture and deployment, microservices configuration,
  monitoring and logging, and advanced Jenkins configuration.

Recruitment process:
- Application screening.
- Prescreening call (40 minutes), technical interview (60 minutes), and final
  interview (40 minutes), typically over two to three weeks.
- Job offer.

Offer:
- Competitive compensation based on experience.
- 19 business days of flexible PTO.
- Fully remote work with flexible hours within CET.
- Conference and community-event participation.

Application form requires Telegram, expected gross monthly salary in EUR, country
of residence, and answers about DDD, Symfony, and fluency in Ukrainian or Russian.
