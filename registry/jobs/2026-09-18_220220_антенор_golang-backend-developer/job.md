# Golang Backend Developer

Posted: 2026-09-18

«Антенор» — українська IT-компанія, яка розробляє та впроваджує технологічні рішення для супутникового моніторингу транспорту. Наші продукти використовуються бізнесом для контролю транспорту, аналізу даних та оптимізації операційних процесів.

Ми розширюємо команду розробки та шукаємо Golang Backend Developer, який допоможе розвивати backend-сервіси та забезпечувати стабільну роботу серверної частини наших рішень.

Що потрібно робити

- Розробляти та підтримувати backend-сервіси на Go (Golang).
- Проєктувати та реалізовувати REST API і gRPC-сервіси.
- Працювати з мікросервісною архітектурою.
- Брати участь у проєктуванні та розвитку технічної архітектури.
- Розробляти новий функціонал і вдосконалювати наявні сервіси.
- Оптимізувати продуктивність, надійність і масштабованість backend-рішень.
- Налаштовувати та підтримувати серверну версію програмного рішення на стороні клієнта.
- Виконувати розгортання, оновлення та технічний супровід серверного середовища клієнта.
- Взаємодіяти з frontend-, mobile-, QA- та іншими технічними спеціалістами.
- Брати участь у пошуку та усуненні технічних проблем.

Що для нас важливо

- Комерційний досвід розробки на Go (Golang).
- Розуміння принципів побудови REST API та gRPC.
- Практичний досвід роботи з мікросервісною архітектурою.
- Розуміння принципів роботи баз даних.
- Досвід роботи з Git та Docker.
- Розуміння Linux і базових принципів налаштування серверних середовищ.
- Досвід розгортання та підтримки backend-сервісів буде перевагою.
- Розуміння принципів роботи frontend та взаємодії frontend із backend через API.
- Уміння самостійно вирішувати технічні задачі та відповідально ставитися до результату.

Буде плюсом

- Досвід роботи з Kubernetes.
- Досвід налаштування CI/CD.
- Знання PostgreSQL, Redis або інших сучасних систем зберігання даних.
- Досвід роботи з системами моніторингу та логування.
- Розуміння принципів інформаційної безпеки серверних рішень.

Ми пропонуємо

- Роботу над власними технологічними продуктами.
- Цікаві backend-задачі та можливість впливати на технічні рішення.
- Роботу з сучасним стеком Go, REST API, gRPC та мікросервісною архітектурою.
- Сильну технічну команду та можливість професійного розвитку.
- Конкурентну заробітну плату за результатами співбесіди.
- Віддалений формат роботи.
- Комфортні умови роботи та підтримку команди.

Якщо вам цікаво розробляти backend-рішення на Go та працювати не лише з кодом, а й із реальним розгортанням продукту на стороні клієнта — будемо раді познайомитися.
