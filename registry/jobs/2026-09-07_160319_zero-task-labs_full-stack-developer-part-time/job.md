**Більше про нас: **Займаємось розробкою кастомних цифрових продуктів і впровадженням AI-автоматизації. Наші клієнти — стартапи з раундами та середній бізнес, яким потрібен не просто вендор, а партнер, що думає бізнесом. В портфелі — SaaS-продукти, CRM/ERP-рішення, AI-powered застосунки.

**Умови:**

🌍 Формат: повністю remote, тайм-зона — Центральна/Східна Європа;

**
Про основний проєкт:**

Продукт складається з трьох незалежних репозиторіїв одного e-commerce магазину:
— backend — API на Laravel 10 (DDD-архітектура, ~40 доменів: Product, Order, Cart, Store, Promocode тощо)
— admin — адмін-панель на React 18 + Redux Toolkit
— frontend — публічний сайт на Next.js 14 (SSR, i18n uk/ru/en)
Усі три звертаються до одного бекенду через Sanctum-автентифікацію. Фронтенд і адмінка побудовані за Feature-Sliced Design (`entities → features → widgets → pages`).

****
