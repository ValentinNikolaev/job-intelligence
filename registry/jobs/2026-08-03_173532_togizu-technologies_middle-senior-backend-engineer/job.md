# Middle/Senior backend engineer

Posted: 2026-08-03

Togizu Technologies is looking for an experienced Backend engineer to join our team.

You will work under the leadership of the Solution Architect and report to him.

**ABOUT CANDIDATE:**

**NOTE**: If you think you don’t fit all these requirements, but you are an experienced backend engineer, and If you are interested in this project, feel free to contact us anyway.

- **PHP; Symfony as a Plus;** or any other modern PHP framework. Our main framework is Symphony (the latest version).
- **Docker/k8s**. You don’t have to maintain infrastructure, but you should understand how it works to communicate with the DevOps team.
- **Databases: Postgres, Redis, Elastic**.
Our primary database is Postgres, but we’ll use other NoSQL databases for specific services, like Redis for caching, Elasticsearch for logs and analytics, etc.
- **SOA: service-oriented architecture**.
We’ll have different services (not microservices).
So you’ll need at least a basic understanding of standard practices and issues in such an architecture.
- **Network protocols: TCP, HTTP, Web socket, GRPC, AMQP**.
It is important to understand how it works since we’ll have different services based on different technologies, and those services should be able to communicate with each other.
- **GIT**
- **Understanding different API models: REST, JSON-RPC, GraphQL, etc**. For some services, REST is not enough. We’ll need complex APIs.
- **OOP principles. SOLID, DDD, CQRS. **You need to understand when you should use it and when you shouldn’t.
- **NodeJS**: Some services will be written in NodeJS (like real-time Web socket services, reverse proxies, etc.), so it’s good to have an experience with Node.
- **Python**: We use Python for many scripts, like automating routine tasks, infrastructure configuration, monitoring, taking backups, etc. It’s not required, but will be a plus.
- **Knowledge of Go is a plus. **
- **AI proficiency.**
- **Blockchain basics**: You have to understand how it works since we are a crypto platform.
- You will work with English-speaking stakeholders, so intermediate or higher level of English is a must
