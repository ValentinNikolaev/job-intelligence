# Backend Developer(PHP)

Posted: 2026-09-07

**Evoplay — одна з провідних продуктових IT-компаній України, яка працює на міжнародному ринку та створює комплексні B2B-рішення для індустрії онлайн-ігор.**
Шукаємо досвідченого PHP Developer (Middle/Senior), який приєднається до команди розробки маркетингової автоматизаційної платформи.
Проєкт — enterprise-grade backend із модульною архітектурою, багатоканальною системою повідомлень та високим навантаженням. Важлива глибока експертиза у backend-розробці, розуміння сучасних підходів та вміння працювати з існуючим кодом і складними системами.

**Про роль:**
Кандидат зможе брати участь у технічному дизайні нових рішень, впливати на архітектуру окремих компонентів і працювати над підвищенням надійності існуючих сервісів. У роботі буде можливість отримати практичний досвід із Go, Kubernetes та MySQL/PostgreSQL базами обсягом у кілька терабайтів.

**Обов’язки:**

- Розробка нового та підтримка існуючого функціоналу на PHP.
- Написання тестів для нового та існуючого функціоналу.
- Проєктування змін у базах даних з урахуванням обсягів даних і навантаження.
- Робота з сервісами розгорнутими у Kubernetes.
- Аналіз та оптимізація SQL-запитів, індексів і таблиць в MySQL та PostgreSQL.

**Вимоги:**

- Досвід комерційної розробки на PHP та роботи з одним із сучасних PHP-фреймворків: Symfony, Laravel або Yii.
- Впевнене розуміння ООП, SOLID, Dependency Injection та принципів побудови підтримуваного коду.
- Досвід роботи з MySQL або PostgreSQL.
- Розуміння SQL, індексів, транзакцій та принципів оптимізації запитів.
- Досвід роботи з Redis або сумісними сховищами.
- Досвід роботи з брокерами повідомлень.
- Досвід написання тестів за допомогою сучасних фреймворків.

**Буде плюсом:**

- Досвід роботи з мікросервісною архітектурою.
- Досвід роботи з Docker та Kubernetes.
- Досвід роботи з Elasticsearch, OpenAPI або GraphQL.
- Досвід використання інструментів статичного аналізу, наприклад: PHPStan або Psalm.
- Досвід роботи з Go.
- Досвід роботи з великими обсягами даних або високонавантаженими системами.
- Досвід frontend-розробки на JavaScript/TypeScript.
- Досвід роботи з React, Vue.js або Angular.

**Що ми пропонуємо:**

- Self-learning бібліотеку та доступ до платних курсів.
- Групові обговорення та індивідуальні сесії з психологом.
- 20 робочих днів оплачуваної відпустки та лікарняні.
- Вихідний у день народження.
- Медичне страхування.
- Зручний офіс біля метро в центрі міста.
- Подарунки на річниці.
- L&D-центр із курсами для співробітників.
