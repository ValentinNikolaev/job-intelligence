Привіт!
Ми, **Boosta — холдингова ІТ-компанія**, яка створює, розвиває та інвестує в digital-бізнеси з глобальним потенціалом. Сьогодні з нами співпрацюють понад 700 фахівців з різних куточків світу, а нашими продуктами та сервісами користуються мільйони юзерів.

Наразі до одного з наших бізнесів Traffic7 ми шукаємо **Full Stack Developer**, який буде розробляти та підтримувати масштабовані fullstack-рішення, інтегруючи сучасні технології та AI-інструменти у процес розробки продукту.

**Traffic7 **— проєкт, який створює та розвиває digital-продукти та масштабує їх за допомогою експертизи у performance-маркетингу.

**У ролі Full Stack Developer разом з командою ти будеш:**

- Проєктувати, розробляти та підтримувати fullstack-функціональність frontend та backend (основна мова — PHP, Node.js — за потреби).
- Розробляти та підтримувати server-to-server (S2S) інтеграції з рекламними платформами (Facebook, Google, TikTok) та AppsFlyer.
- Проєктувати та підтримувати схеми баз даних і оптимізувати запити (MySQL, PostgreSQL).
- Реалізовувати та підтримувати стратегії кешування за допомогою Redis.
- Створювати, підтримувати та вдосконалювати CI/CD-пайплайни за допомогою GitHub Actions.
- Контейнеризувати та керувати сервісами за допомогою Docker.
- Налаштовувати та підтримувати Cloudflare (CDN, security rules, DNS).
- Активно використовувати AI coding agents (наприклад, Claude Code) як частину щоденного процесу розробки для прискорення імплементації, рефакторингу та налагодження.
- Виявляти та усувати проблеми у production, забезпечуючи надійність і продуктивність системи.
- Співпрацювати з продуктовою, маркетинговою та QA-командами для реалізації функціоналу відповідно до бізнес-цілей.
- Слідкувати за новими інструментами, фреймворками та практиками AI-assisted development і проактивно пропонувати покращення процесів.

** **

**Ти — наш match, якщо:**

**Frontend & Backend Development**

- Впевнене володіння PHP (основна backend-мова).
- Практичні знання Node.js (додатковий/допоміжний стек).
- Глибоке розуміння fullstack-архітектури та проєктування API.

**Architecture & Design Patterns**

- Глибоке знання принципів програмної архітектури (наприклад, MVC, мікросервіси, event-driven architecture).
- Хороше розуміння патернів проєктування (Factory, Singleton, Strategy, Repository тощо).
- Вміння обирати відповідні архітектурні підходи залежно від вимог проєкту.
- Досвід написання чистого, підтримуваного та масштабованого коду.

**Databases & Caching**

- MySQL (проєктування схем, оптимізація запитів).
- PostgreSQL.
- Redis (кешування, керування сесіями, черги).

**DevOps & Infrastructure**

- Docker (контейнеризація, багатосервісні середовища).
- GitHub Actions (налаштування CI/CD pipeline).
- Досвід побудови та підтримки CI/CD workflows.
- Cloudflare (CDN, security rules, керування DNS, Workers буде перевагою).

**Marketing & Attribution Integrations**

- Інтеграція AppsFlyer та налаштування відстеження подій.
- Server-to-server (S2S) інтеграції з Facebook, Google та TikTok Ads.

**AI-Assisted Development (Must-have)**

- Практичний досвід роботи з AI coding agents (наприклад, Claude Code).
- Розуміння agentic loops та того, як автономні агенти планують, виконують ітерації та досягають результату.
- Вміння ефективно формулювати промпти, керувати процесом генерації та перевіряти AI-згенерований код.
- Знання найкращих практик інтеграції AI-агентів у процес розробки.

**Nice to Have**

- Досвід моніторингу продуктивності та налагодження production-середовищ.
- Розуміння найкращих практик безпеки для payment/ad-tech інтеграцій.
- Досвід роботи у швидкому, ітеративному продуктовому середовищі.
