Proceed with a PHP-led application if the candidate is comfortable with the role's seniority and the practical frontend share. Before applying, confirm Vue.js or other frontend work only if the candidate can describe it from real experience, and ask how SoftHouseGroup uses AI coding tools and reviews generated code.
