## Technical Interview

**High Priority**

- PHP and Laravel/Symfony backend design: service structure, domain boundaries, queues, APIs, validation, testing, and maintainability.
- SQL and database performance: indexing, query optimization, load reduction, schema changes, migration safety, transaction boundaries.
- REST APIs and integrations: lifecycle tracking, retries, idempotency, error handling, backpressure, observability.
- Modernization: how to refactor legacy systems safely, migrate services, reduce risk, and improve delivery practices.
- CI/CD and deployment automation: GitHub Actions, Helm, ArgoCD, release safety, rollback thinking.
- Cloud and Kubernetes: AWS, ECS-to-Kubernetes migration, service runtime concerns, monitoring, and operational reliability.
- Technical leadership: roadmap input, task evaluation, interviewing, mentoring, and technical decision-making.

**Medium Priority**

- Data processing pipelines: queue-based processing, delivery guarantees, downstream routing, monitoring.
- Elasticsearch and RabbitMQ: search/query performance, queues, retries, operational failure modes.
- System design for customer-facing SaaS platforms: scalability, reliability, and business-critical workflows.
- Security and compliance basics: use Sixt PCI DSS/GDPR experience only if asked, since it is not central to the tailored CV.

**Low Priority**

- Blockchain/NFT details from Hyprr unless the interviewer asks about that product.
- Email infrastructure deep dives beyond using PDFfiller as a scaling and leadership story.
- Frontend topics, because the vacancy is backend-focused.

Practice technical explanations:

- How you reduced database load at airSlate without disrupting production.
- How you would modernize a PHP/Laravel monolith or legacy service incrementally.
- How you design an API integration with retries, idempotency, monitoring, and clear failure handling.
- How you decide between synchronous APIs, queues, and event-driven processing.
- How you would support CI/CD and deployment automation for a small but growing engineering team.
