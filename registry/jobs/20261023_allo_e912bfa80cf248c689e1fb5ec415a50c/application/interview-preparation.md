## Technical Interview

**High Priority — PHP and object design.** Refresh language features, types, dependency injection, interfaces, composition and error handling. Use a small service exercise to explain OOP and SOLID through actual decisions. The selected evidence supports PHP and frameworks generally, not the exact preferred modern versions.

**High Priority — APIs and integration contracts.** Practise request validation, authentication, idempotency, retries, pagination, error categories and backward compatibility. The confirmed Crutrade integration supplies real production scope. JSON-RPC knowledge should be discussed honestly as distinct from demonstrated REST API work.

**High Priority — service architecture.** Sketch an incremental extraction from a hypothetical monolith. Identify a boundary, data ownership, contracts, observability and rollback. Explain what must remain compatible while consumers move. This is a design exercise, not a past project claim. Do not rename ordinary event publication as Event Sourcing or assume that every service needs CQRS.

**High Priority — databases and performance.** Review transactions, indexes, query plans, locking and workload distribution. Explain what the airSlate team observed and how Prometheus informed evaluation. Prepare the actual query or bottleneck example from memory, acknowledging any missing baseline.

**Medium Priority — coding and tests.** Practise a clear PHP API implementation and tests around contract and failure behaviour. Discuss unit versus integration coverage without inventing a testing strategy from the CV's broad delivery history.

**Medium Priority — infrastructure and messaging.** Review AWS service boundaries, queue delivery semantics, retry policies and operational metrics. EventBridge is supported at CRURATED and SQS in the Go gateway. Explain which facts belong to which system rather than combining them into an invented architecture.

**Medium Priority — AI development.** Separate LLM product engineering from using agents while coding. Prepare the actual support-agent actions and evaluation work. Ask what practical AI-tool usage the role expects. **Low Priority — MCP and preferred patterns:** learn their concepts enough to discuss a possible exercise, but do not claim production implementation without evidence.
