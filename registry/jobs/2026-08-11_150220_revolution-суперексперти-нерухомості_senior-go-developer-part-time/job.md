# Senior Go Developer (Part time)

Posted: 2026-08-11

Ми — провідна агенція нерухомості, яка активно впроваджує інновації та технології для трансформації ринку. Наша місія — створювати виняткову цінність для клієнтів, пропонуючи сучасні рішення та сервіси. Ми віримо, що технології є ключем до успіху, тому інвестуємо в сильні команди, які будують майбутнє нерухомості та формують нові стандарти якості.

**Обовʼязки:**
— Розробляти та підтримувати високопродуктивні backend-сервіси на Golang, від концепції до продакшну.
— Оптимізувати SQL-запити, ефективно працювати з Redis та Elasticsearch в умовах високих навантажень.
— Проєктувати та розвивати API (REST, GraphQL, gRPC), забезпечуючи їхню гнучкість та масштабованість.
— Підтримувати CI/CD-пайплайни та впроваджувати найкращі практики GitFlow.
— Налаштовувати системи моніторингу, алертів та observability, щоб забезпечити стабільну роботу сервісів.
— Активно брати участь в архітектурних рішеннях, проводити code review та менторити молодших колег.

**Вимоги:**
— Від 5 років комерційної розробки на Golang, включно з проєктуванням, розробкою та підтримкою backend-сервісів у production.
— Глибоке розуміння мікросервісної архітектури, принципів декомпозиції, міжсервісної взаємодії та здатність оцінювати trade-offs між монолітом та мікросервісами.
— Експертні знання PostgreSQL: проєктування схем, оптимізація SQL-запитів, індекси, робота під високим навантаженням.
— Досвід проєктування API (REST, GraphQL, gRPC), розуміння версіонування, документації та забезпечення зворотної сумісності.
— Здатність працювати автономно, без детальних технічних завдань, у середовищі з високим рівнем невизначеності.
— Вміння ефективно взаємодіяти з нетехнічними стейкхолдерами, перекладаючи складні технічні рішення на мову бізнесу.
— Підхід до розробки, що відповідає масштабу продукту, без надмірного over-engineering.
— Готовність ділитися знаннями та досвідом, сприяючи розвитку команди.
— Відвертість в оцінках, здатність прямо вказувати на проблемні моменти.

**Буде плюсом:**
— Досвід роботи з Redis (кешування, черги) та Elasticsearch (пошук, агрегації).
— Впевнене володіння Docker / Docker Compose, досвід деплою та супроводу production-середовищ.
— Знання та досвід налаштування CI/CD (GitHub Actions або аналогів) та використання GitFlow.
— Досвід роботи з системами моніторингу та observability: метрики, логи, алерти (Prometheus/Grafana або аналогів).
— Досвід прийняття архітектурних рішень на рівні системи: вибір технологій, ADR, технічний аудит.
— Навички роботи з frontend-частиною продукту (React + TypeScript) — full stack профіль.
— Досвід інтеграцій зі сторонніми API: Google Workspace/Calendar, Telegram Bot API, платіжні сервіси.
— Досвід використання AI/LLM API (Claude, Gemini, OpenAI) у продуктових фічах.

**Умови:**
— Віддалена та часткова зайнятість
— Пропонуємо гідну оплату праці, що відповідає вашому досвіду та ринковим стандартам.
— Можливість працювати над цікавими та складними проєктами, що впливають на ринок нерухомості.
— Застосування передових інструментів та підходів у розробці.
— Динамічна та відкрита до ідей команда, орієнтована на результат та постійне вдосконалення.
