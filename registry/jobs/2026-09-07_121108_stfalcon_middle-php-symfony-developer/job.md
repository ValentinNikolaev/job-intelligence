# Middle PHP (Symfony) Developer

Posted: 2026-09-07

**Stfalcon** — українська IT-компанія з понад 16-річною історією розробки веб- та мобільних продуктів для бізнесу. Ми працюємо з проєктами у сферах логістики, транспорту, охорони здоров’я та фінтеху, де важливі стабільність, масштабованість і продумана архітектура.

PHP та Symfony — одна з наших ключових технологічних експертиз. Ми працюємо зі складною бізнес-логікою, високонавантаженими системами та дотримуємося Symfony Best Practices. Також команда робить внесок в Open Source — зокрема, наш **DoctrineRedisCacheBundle** використовується для роботи з кешуванням у Symfony-проєктах.

Зараз ми розширюємо Backend-команду та шукаємо **Middle PHP (Symfony) Developer**, якому важливі якість коду, зрозуміла архітектура та можливість працювати над технічно змістовними задачами.

### **Над чим ви будете працювати (Обов’язки):**

- Проєктування, розробка та масштабування Backend-частини вебзастосунків з використанням PHP 8+ та сучасних версій фреймворку Symfony.
- Розробка та архітектурне проєктування надійних RESTful API для забезпечення комунікації між клієнтськими застосунками, мікросервісами та зовнішніми системами.
- Робота з реляційними базами даних (PostgreSQL): проєктування оптимальних схем даних, написання та профілювання складних SQL-запитів.
- Написання чистого, підтримуваного коду з беззаперечним дотриманням принципів SOLID та стандартів кодування PSR-12.
- Покриття бізнес-логіки Unit та функціональними тестами з використанням PHPUnit, забезпечення високого відсотка покриття коду (Code Coverage).
- Проведення регулярних Code Review для підтримання високих стандартів інженерної культури всередині команди.
- Тісна крос-функціональна співпраця з Frontend-інженерами, спеціалістами з якості (QA) та Project-менеджерами в рамках гнучких методологій (Scrum/Agile).

### **Що ми очікуємо від вас (Обов’язкові вимоги):**

- **Від 3 років** підтвердженого комерційного досвіду розробки складних застосунків на PHP.
- Впевнений практичний досвід роботи з екосистемою **Symfony**: розуміння Dependency Injection, Event Dispatcher, Console, Forms, Security та механізмів Autowiring.
- Глибоке розуміння парадигм ООП, класичних патернів проєктування та принципів побудови архітектури вебзастосунків (MVC, REST).
- Практичний досвід роботи з ORM (переважно Doctrine), включно з використанням PHP Attributes для мапінгу сутностей.
- Впевнені знання SQL та досвід роботи з реляційними базами даних (PostgreSQL або MySQL).
- Досвід роботи з системами контролю версій (Git, Git Flow).
- Розуміння стратегій кешування та практичний досвід інтеграції сховищ ключ-значення (Redis / Memcached).
- Базове розуміння операційної системи Linux та впевнений досвід контейнеризації локального середовища розробки за допомогою Docker / Docker-compose.
- Рівень англійської мови: **Intermediate / Upper-Intermediate (B1-B2)** — достатній для вільного читання технічної документації та письмової комунікації у трекерах задач.

### **Буде плюсом:**

Додатковою перевагою стане досвід або розуміння суміжних технологій:

- нереляційних баз даних — MongoDB, DynamoDB;
- Elasticsearch та інших систем повнотекстового пошуку;
- брокерів повідомлень — RabbitMQ, Kafka;
- мікросервісної архітектури та принципів побудови розподілених систем;
- CI/CD;
- інструментів статичного аналізу та контролю якості коду — PHPStan, PHP CS Fixer;
- **Node.js** на базовому рівні.

У частині наших систем можуть використовуватися асинхронні мікросервіси або Serverless-компоненти, тому розуміння Node.js буде корисним для роботи із суміжними частинами архітектури.

### **Чому Stfalcon:**

**Сильна Backend-команда.**
Поруч будуть інженери з багаторічним досвідом, з якими можна обговорювати архітектурні рішення, отримувати якісний code review та професійно зростати.

**Технічно змістовні проєкти.**
Ми працюємо не лише з типовими CRUD-задачами. У проєктах є складна бізнес-логіка, інтеграції, оптимізація продуктивності, API, високі навантаження та архітектурні виклики.

**Стабільність.**
Stfalcon працює на ринку понад 16 років. Ми маємо сформовану команду, процеси та досвід реалізації довгострокових продуктів.

**Гнучкий формат роботи.**
Можна працювати віддалено або з офісу. Початок робочого дня — о **9:00 або 10:00**.

**Прозорий професійний розвиток.**
У компанії діє системний процес Performance Review, тому розвиток і перегляд компенсації не залежать від випадкових домовленостей.

**Підтримка навчання та wellbeing.**
Компанія співфінансує:

- профільне навчання;
- заняття з англійської;
- абонементи до спортивних залів.

Також надаємо бухгалтерський та юридичний супровід співпраці.

### **Як проходить процес найму:**

Ми намагаємося зробити процес максимально зрозумілим та не розтягувати його зайвими етапами.

**1. HR Interview — 20-30 хвилин**
Знайомимося, говоримо про ваш досвід, очікування та формат роботи. Розповідаємо про компанію, команду й актуальні проєкти.

**2. English Check — до 15 хвилин**
Коротка перевірка рівня англійської для робочої комунікації.

**3. Оцінка технічного бекграунду**
Можна виконати невелике профільне тестове завдання **або** надати приклади власного коду — GitHub, Open Source contributions чи інші репрезентативні роботи.

**4. Technical Interview — до 60 хвилин**
Спілкування з Tech Lead про Symfony, архітектуру, підходи до розробки та реальні інженерні кейси. Без формату «100 теоретичних питань за годину».

**5. Job Offer**
Якщо бачимо взаємний match — переходимо до обговорення фінальної пропозиції та старту співпраці.

### **Хочеш до нас?**

Якщо тобі близький інженерний підхід, Symfony — не просто рядок у CV, а робочий інструмент, і хочеться працювати в команді, де якість коду справді має значення — **надсилай резюме**.

Будемо раді познайомитися.
