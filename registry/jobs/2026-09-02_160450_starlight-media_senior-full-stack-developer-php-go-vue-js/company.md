# Starlight Media

Starlight Media — медіакомпанія № 1 в Україні, провідний виробник та дистриб’ютор контенту, який обирають мільйони українців. До складу Starlight Media входять: ТОП-3 канали за дивленням розважального контенту — СТБ, Новий канал, ICTV2, лідер інформаційного мовлення ICTV, канали ОЦЕ ТБ, Твій серіал, Твоє кіно, Super+.
