# Senior Full-Stack Developer (PHP / Go / Vue.js)

**Starlight Media** — одна з найбільших медіагруп у Східній Європі, виробник та дистриб’ютор відеоконтенту, улюблених програм і серіалів мільйонів українців, якість та актуальність яких забезпечує нам лідерство. Понад половину українського ТБ-продукту, який ви бачите на екранах телевізорів чи у соцмережах, виробляємо саме ми. **Starlight Media** об’єднує телеканали **СТБ, Новий канал, ICTV, ICTV 2, ОЦЕ**, **Твій серіал**, **Super+**, **бренд «Твоє кіно»**, власний продакшн і компанії із оренди техніки та виготовлення видовищних декорацій для шоу світового рівня.

**Starlight Media** — перша українська компанія, що підтримала глобальний рух за сталий розвиток. Ми сприяємо повному забезпеченню прав людини, подоланню будь-яких проявів дискримінації, розширюємо корпоративні можливості для кар’єрної реалізації жінок і розглядаємо різноманіття та інклюзивність як невід’ємну складову своєї корпоративної культури.

**Starlight Media** має відзнаку компанії, дружньої до ветеранів, від Veteran Hub і розробила власну корпоративну стратегію із підтримки ветеранів та ветеранок російсько-української війни. Ми робимо це для того, щоб сприяти формуванню гідних умов для працевлаштування, реабілітації, адаптації українських військових по завершенню служби і якісному відображенню їх досвіду і потреб в контенті.

І сьогодні Департамент Digital** Starlight Media** запрошує до своєї команди **Senior Full-Stack Developer (PHP / Go / Vue.js).**

**Вашими задачами будуть:**

· розвиток і підтримка існуючих веб-платформ (зокрема [Teleportal.ua](http://Teleportal.ua)), розробка нових модулів, сервісів та API, а також технічне підсилення senior-розробника/архітектора;

· розробка та підтримка веб-додатків на PHP (Yii2, Laravel);

· написання та розширення сервісів на Go (або готовність розробляти та розширювати сервіси під керівництвом архітектора);

· розробка та доробка клієнтської частини на Vue.js та Vanilla JS (SPA-архітектура, інтеграція з REST API, DOM, кастомні скрипти);

· проєктування та оптимізація баз даних MySQL (написання та оптимізація складних запитів, робота з індексами);

· проєктування та інтеграція REST API, обробка вебхуків (Webhooks) і зовнішніх сервісів;

· рефакторинг існуючого коду, виправлення багів, покриття критичних вузлів тестами та ведення технічної документації.

### Наші очікування від вас:

· вища профільна освіта та досвід роботи від 3 років;

· впевнені знання PHP 8.x (ООП, шаблони проєктування) та практичний досвід з Yii2 та/або Laravel;

· досвід розробки на Go (Golang) або міцна база та бажання писати сервіси на цій мові;

· хороші знання JavaScript (ES6+), HTML5/CSS3, досвід з Vue.js та розуміння принципів побудови SPA, реактивності й AJAX/Fetch;

· практичні навички роботи з MySQL / MariaDB (транзакції, індекси, побудова ефективних SQL-запитів);

· володіння інструментами Git, Docker (на базовому рівні для локального розгортання), Composer, npm/yarn, REST API, Webhooks;

· досвід роботи з технічною SEO-структурою та мікророзміткою (Schema.org, JSON-LD) буде перевагою;

· розуміння принципів мікросервісної чи модульної архітектури буде перевагою;

· здатність швидко розбиратися в існуючому коді без прагнення «переписати все з нуля»;

· рівень володіння англійською мовою B1-B2;

· уважність до деталей: написання охайного коду (Clean Code), турбота про безпеку API та валідацію даних;

· розвинені навички командної роботи, вміння ставити правильні запитання та сприймати architectural review.
