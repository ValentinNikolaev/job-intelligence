# Senior PHP Engineer (Vanilla PHP)

Posted: 2026-09-08

***Remote · Full-time · Payments Platform ***

We’re staffing a PHP Engineer for a team at a payments company. The team handles card-not-present processor integrations, transactions, and related payment functionality — any transaction where the card isn’t physically present (online payments).

*Important:* the team works in vanilla PHP without a framework. Framework background is fine, but comfort working without one is required.

**Requirements**
**Must-have:**
• Strong vanilla PHP experience — comfortable working without a framework day-to-day
• Backend development — primary focus (90% of time)
• Ability to work on sprint tickets, code reviews, daily stand-ups
• Communication skills for Slack-based team collaboration
• English — B2-C2, sufficient for daily team communication

**Nice-to-have:**
• Experience in payments, fintech, or e-commerce domain
• CNP / processor integration experience
• Basic frontend skills (JavaScript, HTML/CSS) for occasional frontend tasks
• Agile / Scrum experience

**Responsibilities:**
• Code and work on sprint tickets on the CNP team
• Develop and maintain backend payment processing functionality
• Processor integrations and transaction handling
• Code review with team members
• Participate in daily stand-ups and weekly planning
• Communicate via Slack with team and cross-functional partners
• Occasional frontend work (~10% of time)
