## Technical Interview

**High Priority — distributed delivery.** Explain the production event system, source and downstream boundaries, event schemas, routing and backpressure. Practise discussing ordering, duplicates, acknowledgement and recovery. Distinguish the mechanisms actually used from improvements you would propose in a new system. Queue experience is relevant, but does not prove Kafka semantics or expertise.

**High Priority — production migration.** Walk through the Snowflake change from separate pipelines to a shared ingestion and delivery engine. Explain the source-backed no-downtime outcome and removal of full-history reads. Be ready to discuss what was checked before, during and after deployment. Do not invent an automated parity framework, a regional cutover or a rollback mechanism that was not actually used.

**High Priority — Go systems work.** Review concurrency, cancellation, memory and resource limits, error handling, service shutdown and external-call boundaries. Practise a bounded ingestion worker or adapter exercise. Explain how failures remain visible and how repeated work avoids unintended effects. These are likely assessment topics, not additional CV claims.

**High Priority — cloud and infrastructure.** Prepare the actual AWS, Kubernetes and Terraform responsibility boundaries. Explain what you personally configured and what another engineer or SRE owned. Terraform's presence in the stack does not alone establish advanced multi-cloud provisioning. Ask which infrastructure tasks dominate the role.

**Medium Priority — streaming frameworks.** Learn the basic execution and recovery models of Spark and Delta Lake, and the differences from application event queues. Keep new learning separate from production experience. Review how log pipelines handle late data, duplication, schema changes and retention.

**Medium Priority — observability and database work.** Prepare Prometheus/Grafana examples, the database-load result and API performance work. Explain the observed consequence rather than listing dashboards.

**Medium Priority — AI coding tools.** Bring factual examples of daily coding assistance if available, including mistakes and review checks. LLM product integration is a separate ability.
