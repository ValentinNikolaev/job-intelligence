Use the airSlate stability example and distinguish documented work from areas you would investigate in a new system.

**High Priority — cloud and delivery:** review ECS-to-Kubernetes migration, Helm, GitHub Actions, ArgoCD, deployment readiness, observability, and rollback thinking. Neting expressly names cloud-resource support and continuous development.

**Medium Priority — system design:** prepare a whiteboard approach for a client web application: requirements, boundaries, data model, API contracts, authentication, observability, deployment, and operational ownership. Make design trade-offs conditional on facts supplied in the interview.

**Medium Priority — front-end integration:** prepare to explain how a backend collaborates with a front-end team on API contracts, errors, versioning, and testing. Do not claim JavaScript ES6, Angular, HTML5, or CSS3 proficiency unless you can confirm it.

**Low Priority — other languages/frameworks:** Symfony is supported and can be mentioned. Do not claim Python or Java expertise because the evidence does not support it.
