# Application analysis: Giraffe Software Senior Golang Developer

## Vacancy Summary

Giraffe seeks a senior engineer for an enterprise project and resource management platform. The core is Go backend development, REST APIs, distributed event-driven services and data pipelines. PostgreSQL, Redis, Elasticsearch, AWS, Docker, CI/CD, NoSQL and React are named requirements. Messaging and infrastructure as code are advantages. The client meeting is in English and the position is remote, with cooperation described as private entrepreneurship. Five years of commercial Go and backend development are requested. The posting also invites candidates who do not meet every requirement.

## Red Flags

1. React is a stated requirement and no confirmed React delivery appears in the reviewed evidence. Ask about the proportion of frontend work and actual experience.
2. Redis and MongoDB are named technologies. SQS and other database experience are related, but do not prove either specific skill. Confirm personal use before making claims.
3. Docker and AI-assisted engineering tool use are not established in the candidate records. Confirm them separately; an AI product integration is not proof of coding-assistant usage.
4. The candidate has a registered B2B entity, but its jurisdiction is unspecified. Ask whether contracting from Italy through that entity is acceptable and whether remote work has location restrictions.
5. The application form requires a USD salary expectation. A vacancy-specific benchmark must be prepared using the team's physical pay market and evidenced policy before entering a number. No benchmark has been calculated here.
