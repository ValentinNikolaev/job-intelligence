# Application Analysis

## Vacancy Summary

Wooden Sword Games seeks a Senior PHP Developer for backend features in a high-load live mobile RPG. The stated core is a Laravel/PHP REST API and a Nakama TypeScript runtime. Responsibilities include API integration, feature implementation, tests, reviews, hot-path profiling, and documentation of RPC and storage contracts. The posting explicitly asks for independent Laravel work, five or more years of backend experience, TypeScript, PostgreSQL, SQL, transactions, and locking. Game development, A/B testing, TypeScript test coverage, and push services are preferences.

The candidate directly matches the seniority, PHP/Laravel background, API integration, production ownership, performance orientation, and reviewed A/B-testing experience. The material gaps are Nakama, TypeScript, direct game development, push services, and a specific supported PostgreSQL locking example. Those gaps must remain explicit in a recruiter conversation.

## Strict Hiring Manager Review

Three strengths are breadth of backend experience, credible production ownership, and a recent PHP event-platform story. The CV shows a useful combination of APIs, event-driven systems, and scale. The evidence also supports an A/B-test example and a high-volume operational context.

Three material weaknesses remain. First, the work is not game backend work, so the candidate should state this plainly and connect transferable patterns rather than imply equivalence. Second, the current recent work is Go-heavy; the CV addresses this by leading with the verified PHP CRURATED engagement. Third, TypeScript/Nakama and transaction-locking evidence are absent. The safe response is a learning plan and questions for the team, never invented familiarity.
