# Middle Full Stack Developer (PHP/React)

Posted: 2026-07-31

We are looking for a **Middle Full Stack PHP Developer** to own the growth of our client’s microservice-based e-commerce platform. You will work across core services (products, orders, content, marketing) using modern PHP, React, and AI-assisted workflows.
No prior AI experience? No problem, you will start with standard full-stack tasks and have a clear path to grow into AI engineering on live production features.

**Required Qualifications:**

- 3+ years of experience with PHP 8.x and Laravel or Symfony.
- Solid experience with REST APIs, MySQL/PostgreSQL, and Redis.
- Good understanding of JavaScript (React.js), Blade templates, HTML/CSS.
- Hands-on experience with Docker and Git.
- Experience with or readiness to adopt AI-assisted development tools (Claude Code, Cursor, Copilot).****
- English — B2.

**Responsibilities:**

- PHP Backend (70%): Write and maintain clean PHP code (Laravel/Symfony), build REST APIs, integrate third-party services (payments, shipping, analytics), and manage databases and caching.

- Engineering Standards: Conduct code reviews, ensure test coverage, and work daily with Claude Code (spec-driven, AI-assisted coding & review).

AI Evolution (Optional Path): If you already have AI skills (or as you gain them on the project), you can join existing production AI features and gradually shift up to 100% of your work toward AI engineering.

**Nice to have:**

- Familiarity with OpenAI API, RAG architecture, or vector databases (Pinecone).
- Understanding of microservices, Domain-Driven Design (DDD), or Kubernetes.****
