# PHP Full-Stack Developer

Posted: 2026-08-15

**About the role**

ClassOwl is a school-management system used by educational institutions. We are hiring a Middle+/Senior PHP Full-Stack Developer to join the team and work on our existing product.
The application is built on a custom PHP framework. Most tasks involve extending and improving the current application: adding product functionality, changing web interfaces, maintaining APIs and integrations, and investigating issues reported from staging or production.
The developer will work across backend and frontend parts of a feature. It is important to understand an existing codebase, make changes carefully, and consider how they affect different school installations. We expect the person to take part in a feature from clarification and estimation to implementation and code review.

**What you will work with**

- backend and frontend features in an existing PHP application
- vanilla JavaScript, HTML, CSS, jQuery — not a React/Vue SPA
- MySQL and SQL queries
- REST APIs used by the mobile application
- third-party integrations
- debugging and fixing issues in staging and production

**Responsibilities**

- clarify requirements together with the Business Analyst, asking questions that help narrow down scope where needed
- estimate tasks and discuss solutions with the Lead Developer, considering the impact across different school installations
- review code from other developers and give constructive feedback
- maintain and extend REST APIs used by the mobile application
- integrate and maintain third-party services
- investigate and fix bugs reported by QA, Customer Support, and from staging/production
- write and optimize SQL queries for new and existing functionality

**What we expect**

- 4+ years of PHP web-development experience, including backend and frontend work
- strong knowledge of PHP, vanilla JavaScript, HTML, CSS, and MySQL
- experience writing and optimizing SQL queries
- experience working with an existing (legacy/production) codebase
- ability to work with REST APIs and third-party integrations
- Git and Linux experience
- English at B1 level or higher

**Terms of cooperation**

We offer two cooperation formats to choose from ФОП (standard) and ФОП+ (an extended package with paid vacation, bonuses, and additional compensations). Details of each format are discussed during the interview.
