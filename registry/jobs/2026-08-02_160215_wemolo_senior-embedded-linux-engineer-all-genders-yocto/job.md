# Senior Embedded Linux Engineer (all genders) - Yocto · Python · IoT Edge

Posted: 2026-08-02T14:40:32Z

This position sits close to the embedded world, but it isn't traditional microcontroller firmware work. You'll own the **operating system foundation and platform layer of our IoT devices** - building and evolving our next-generation embedded Linux image - and develop the **Python application layer** that runs on top of it, inside our dockerized main application.

You'll work down at the OS and hardware boundary while shipping features up in the application layer. Typical areas include:

-

Designing and maintaining our **Yocto-based Linux distribution** for ARM devices with limited compute

-

**Security on device, inter-process communication, networking, scheduling, observation**

-

**Over-the-air (OTA) updates** for both the OS and applications

-

Integrating peripherals - watchdog, modem, AI accelerator - and improving their observability

-

Bridging the system layer and the application layer through Python and Bash

The work spans from driver- and kernel-level integration in C/C++, to adapting our Linux distribution with Yocto to the underlying hardware layer, to debugging system-level failures such as memory leaks, up to writing the Python software that turns hardware capabilities into product features.

*You will be expected to pass a live coding interview for this role.*

## **What to expect**

-

**Embedded Linux Platform: **Design, build, and continuously evolve the next generation of our Yocto-based Linux distribution for ARM-powered IoT devices

-

-

**System Integration: **Work across the full stack—from kernel and driver integration to application development—connecting hardware, operating system, and product features

**Device Reliability: **Build secure, observable, and resilient systems, including OTA updates, networking, process communication, scheduling, and device monitoring

-

**Debugging & Troubleshooting: **Analyze and resolve complex issues across the platform, including kernel, drivers, networking, memory management, and application software

-

**Ownership: **Take end-to-end responsibility for your solutions, proactively improve our platform, and help shape engineering best practices
