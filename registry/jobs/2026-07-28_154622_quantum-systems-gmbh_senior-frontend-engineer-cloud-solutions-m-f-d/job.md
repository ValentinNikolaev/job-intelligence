# (Senior) Frontend Engineer – Cloud Solutions (m/f/d)

Posted: 2026-07-28T14:50:45Z

We are looking for a passionate Senior Frontend Engineer who enjoys working with modern web technologies, values clean architecture, and can translate complex requirements into elegant, responsive, and user-friendly solutions. You’ll collaborate with cross-functional teams to deliver products that shape the future of our cloud ecosystem.

As part of our Cloud Team, you will build applications that increase the efficiency of our innovation and maintenance processes, while providing greater control over service workflows and connected devices.

#### **What is your Day to Day Mission:**

-

Design, develop, and optimize front-end applications using Angular (v13+) and Material Design.

-

Build modern, responsive, and lightweight UI components for product features.

-

Write unit tests and integration tests to ensure code correctness and stability.

-

Collaborate with backend engineers, understanding APIs, distributed systems concepts, and ensuring smooth data flow.

-

Participate in code reviews, maintain clean code practices, and ensure high quality in implementations.

-

Use Git effectively—branching, pull requests, merges—and contribute to CI/CD workflows, with Docker involvement.

#### **What you bring to the team:**

-

3-5 years of solid professional experience as a Frontend Engineer or Web Developer.

-

Strong proficiency in TypeScript and Angular (v13+).

-

Knowledge about other similar SPA frameworks is a plus

-

Hands-on experience with Angular Material / Material Design.

-

Appreciation for clean code and building reusable components.

-

Experience in writing both unit and integration tests.

-

Experience with state management (NgRx or Signal Store) is a plus.

-

Ability to work independently, organize your work, and solve problems with attention to detail.

-

Good understanding of web fundamentals and the product development lifecycle.

-

Familiarity with distributed systems concepts and the ability to collaborate closely with backend teams.

-

Experience with Git, basic Docker knowledge, and exposure to CI/CD pipelines.

-

German language skills are a plus.
