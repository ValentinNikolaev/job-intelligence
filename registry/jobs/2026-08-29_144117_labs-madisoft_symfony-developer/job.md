# Symfony developer

Labs Madisoft seeks Symfony developers for a fully remote team working on Nuvola, a SaaS platform used daily by millions of Italian teachers, school staff, students and parents. The role develops new software and features and fixes bugs using Agile methods, pairing and code review; contributes to product decisions; works with object-oriented programming, SOLID, design patterns, DDD, BDD/TDD, Symfony, modern PHP, scalability and performance; and supports migration from a monolith to microservices. Required: motivation and problem solving, strong modern PHP and Symfony knowledge, OOP, clean testable code and alignment with company culture. Desired: DDD, TDD/BDD, microservices/API/event-driven architecture, monolith-to-microservices transition, CI/CD, RabbitMQ and messaging integration patterns. Offer: permanent employment or VAT contractor, full time, RAL 30k–45k depending on seniority, training and benefits.
