# Middle Full-stack Developer

Posted: 2026-08-13

**Не просто код, а твій вплив на мільйони українців**

**Nova Digital** — це технологічне серце екосистеми NOVA, де твій код стає частиною щоденного життя цілої країни.

**Про масштаб наших сервісів:**

• 50+ млн запитів щодня проходять через наші системи
• 10+ млн активних користувачів покладаються на наші рішення

**Ми розвиваємо WEB-додатки для автоматизації логістичних процесів:** планування маршрутів, управління рейсами, моніторингу транспорту в реальному часі та взаємодії з водіями автотранспорту. В команді є як критично важливі backend-сервіси, що працюють з великими обсягами даних і навантаженням, так і внутрішні веб-інтерфейси для користувачів: форми, довідники, CRUD-інтерфейси, аналітичні та операційні екрани.
**Шукаємо Senior Full-stack Developer** із сильним backend-досвідом, який зможе брати участь у розвитку серверної частини продуктів, проєктуванні API, оптимізації продуктивності та за потреби реалізовувати frontend-функціональність для внутрішніх веб-сервісів. Ця роль передбачає не лише розробку задач, а й участь в архітектурних обговореннях, декомпозиції рішень, code review, технічному розвитку продуктів і підсиленні команди.

**Стек проекту:** PHP 8.x, MySQL 8.x, JavaScript, Ext JS, Vue.js 3, Docker, Google Cloud, Google Cloud Pub/Sub, REST/jsonRPC API.

**Що робитимеш як ****Full-stack Developer:**

- Розробляти та підтримувати frontend- і backend-функціональність веб-додатків.
- Реалізовувати користувацькі інтерфейси для внутрішніх веб-сервісів: форми, довідники, таблиці, CRUD-інтерфейси, аналітичні та операційні екрани.
- Інтегрувати frontend із backend API та забезпечувати коректну обробку даних і станів інтерфейсу.
- Розробляти та підтримувати API для взаємодії між компонентами та системами.
- Реалізовувати серверну бізнес-логіку та працювати з базами даних.
- Працювати з SQL-запитами та брати участь у їх оптимізації.
- Працювати з інтеграціями та асинхронною обробкою подій.
- Брати участь у розвитку існуючих систем та реалізації нової функціональності.
- Аналізувати технічні проблеми та разом із командою знаходити способи їх вирішення.
- Брати участь у плануванні, оцінці та декомпозиції задач.
- Взаємодіяти з бізнес-аналітиками, QA, DevOps, архітекторами та іншими розробниками.
- Документувати технічні рішення, інтеграції та складну бізнес-логіку.
- Розвивати власну технічну експертизу.
