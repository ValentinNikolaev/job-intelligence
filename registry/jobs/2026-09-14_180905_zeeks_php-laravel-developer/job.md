# Laravel Backend Developer

Posted: 2026-09-14

**Zeeks** — технологічна компанія, що створює інфраструктурні, аналітичні та сервісні продукти для міжнародного iGaming-ринку.

Шукаємо **PHP (Laravel) Developer,** який долучиться до команди, що розвиває єдину продуктову платформу Zeeks.

**Про проєкт:**

Платформа об’єднує продукти компанії та працює з міжнародними ринками. На позиції ви будете працювати над backend-рішеннями, архітектурою, продуктивністю систем та інтеграціями.

**Ваші майбутні задачі:**

- Розвивати multi-tenant ядро платформи на Laravel.
- Проєктувати моделі даних для мультигео та локалізації.
- Розробляти REST API, workflow-механіки та інтеграції із зовнішніми сервісами.
- Оптимізувати продуктивність систем і баз даних з урахуванням реальних навантажень.
- Працювати над SEO-критичною архітектурою продуктів.
- Брати участь у технічному проєктуванні та code review.

**Що ми очікуємо від вас:**

- Від 5 років досвіду в back-end розробці, з яких від 4 років — із Laravel.
- Впевнене володіння PHP 8+.
- Глибоке розуміння реляційних баз даних і проєктування схем.
- Практичний досвід роботи з API, чергами, кешуванням та інтеграціями.
- Розуміння принципів побудови масштабованих і надійних backend-систем.
- Досвід роботи з Git, Docker та CI/CD.
- Вміння писати чистий і підтримуваний код.
- Англійська — B1 або вище.

**Буде плюсом:**

- Досвід із multi-tenant архітектурою.
