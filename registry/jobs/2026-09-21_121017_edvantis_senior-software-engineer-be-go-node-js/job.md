# Senior Software Engineer BE (Go, Node.js)

Posted: 2026-09-21

We are looking for a Senior Software Engineer to work on the project of our Client who provides a range of media and advertising services, including a proprietary ad server, a media planning tool, and stoppable advertising, among others. The Client is a media-tech company specializing in video streaming and digital advertising. The project focuses on video streaming and digital advertising, specifically Server-Side Ad Insertion (SSAI). The product is a platform that enables personalized ads to be dynamically inserted into live and on-demand video streams while maintaining a smooth, TV-like viewing experience.

As a Senior Software Engineer, you’ll be a hands-on contributor within the team working on development and deployment of components for a rewrite of the server-side ad-insertion SaaS solution in the Go programming language.

### Responsibilities:

- Develop and maintain back-end services using the Go programming language
- Implement new features and integrations for media-/streaming-related products
- Work with REST APIs, gRPC, and Protobuf
- Develop and maintain microservices and distributed back-end components
- Write unit and integration tests and participate in code reviews
- Troubleshoot Production issues and improve application stability and performance
- Optimize services for high-load and low-latency environments
- Work with databases and caching solutions such as MongoDB and Redis
- Containerize applications using Docker and deploy them in Kubernetes environments
- Contribute to CI/CD pipelines and development automation
- Collaborate with other Software Engineers, DevOps Engineers, and product/technical teams
