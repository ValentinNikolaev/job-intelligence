# Middle PHP Backend Developer (AI Oriented)

Posted: 2026-08-26

### Обов’язки

- Розробляти й підтримувати фічі у високонавантаженому моноліті, мікросервісах та внутрішніх пакетах (shared-бібліотека, SDK)
- Інтегрувати API та платіжні системи, працювати з вебхуками та постбеками
- Оптимізувати MySQL-запити, кешування через Redis та фонові задачі через RabbitMQ
- Писати код, безпечний для конкурентного виконання, використовуючи локи, мʼютекси та атомарні операції
- Проводити code review, брати участь у технічних рішеннях, підтримувати статичний аналіз (PHPStan / PHPCS) і тести

### Вимоги

- 2-3+ роки PHP, впевнений Laravel (події/лістенери, черги, DI, сервіс-провайдери, FormRequest)
- Розуміння і використання SOLID принципів на практиці
- MySQL: індекси, план запиту, оптимізація важких вибірок; Redis
- Досвід з чергами (RabbitMQ) і асинхронною обробкою
- Розуміння race conditions і як їх реально закривати
- Інтеграції REST API та платіжних систем, HMAC-підписи, ідемпотентність вебхуків
- Git / GitHub Flow, робота через PR і code review
- Docker для локальної розробки
- Практичний досвід з AI-агентами для кодингу — Claude Code, Codex або аналоги (див. нижче, це не «плюс», це щоденний інструмент у команді)

### Робота з Claude Code — очікуємо

- Уміння вести агента по великій легасі-кодбазі: правильний контекст, CLAUDE.md, memory, посилання на файли
- Розбиття задачі на кроки, plan mode, паралельні сабагенти
- Налаштування власного тулінгу: slash-команди, скіли, хуки, MCP-сервери
- Використання агентів у CI: автоматичний review PR, статичний аналіз, генерація тестів
- Критичне читання результату діяльності агента — перевірка діфів, розуміння, де модель галюцинує, відповідальність за змержений код лежить на розробнику, а не на агенті
- Розуміння вартості/лімітів контексту: коли делегувати, коли зробити руками

### Буде плюсом

- Знання PCI DSS або досвід роботи з server-to-server інтеграціями
- Ubuntu, Nginx, PHP-FPM, cron; CI/CD (GitHub Actions)
- AWS та моніторінг Grafana
- Досвід з антифродом, аналітикою даних, A/B-тестами

- Можливість працювати над міжнародними GameDev продуктами, які зібрали навколо своєї екосистеми мільйони геймерів з усього світу

- Гнучкий робочий графік — ми орієнтуємось тільки на результат
