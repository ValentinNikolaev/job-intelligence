## Technical Interview

**High Priority:** PHP/Laravel/Symfony depth, MySQL, integration design, legacy-code diagnosis, incremental refactoring, task estimation, production reliability and APIs. **Medium Priority:** CI/CD, AWS, architecture boundaries, data migrations and monitoring. **High Priority:** Bootstrap, jQuery, AJAX, HTML/CSS and server-rendered UI, because these are explicit requirements. Establish current hands-on evidence and ask the expected depth, rather than assuming a UI specialist will cover the gap. **Medium Priority:** Apache/Linux, listed as preferred. **Low Priority:** unrelated frameworks outside the existing product stack.

Expect a scenario: inherit an unfamiliar PHP module that mixes admin and customer workflows. Explain how you would map behaviour, identify tests or safe seams, select a small measurable change, preserve data and release in stages. Another likely exercise is an external-service integration: discuss API contracts, idempotency, error handling, auditability and operational support.

Build STAR answers from the CV without invented results. For consolidation, state three workflows, the candidate’s reusable-engine contribution and the consequence of no daily rereads/no downtime. For CRURATED, state technical ownership and the bounded throughput/onboarding/reliability result. For the calling platform, state architecture, review and release with collaborators. A system-design answer should clarify user roles, legacy constraints, data migration safety, incremental release and rollback. UI experience is **High Priority** because SevenPro requires it: prepare an honest gap statement plus questions about how much direct browser-side work is expected.
