Шановна командо з найму Brainstack,

Подаюся на позицію PHP Developer (Billing). Я backend-інженер із понад 15 роками досвіду розробки та вдосконалення production-систем на PHP і Go. Мій основний фокус — прагматична архітектура, інтеграції, продуктивність і надійність сервісів. Для цієї ролі особливо релевантні мій досвід із PHP, Laravel, Symfony, MySQL, RabbitMQ, REST API та мікросервісами, а також звичка відповідати за технічні рішення від аналізу проблеми до стабільної роботи в production.

У airSlate я працював над PHP/Laravel backend-сервісами у високонавантаженому SaaS-середовищі. Я зменшив пікове навантаження на основну базу даних, усунувши вузькі місця та перерозподіливши навантаження, а також знаходив і оптимізував проблемні API та запити. Окремо розробив спільний для продукту пакет логування на Laravel/Symfony відповідно до стандартів міжсервісної взаємодії. Також мігрував сервіси з ECS до Kubernetes і готував процеси доставки з Helm, GitHub Actions та ArgoCD. Цей досвід напряму відповідає завданням Brainstack із розвитку, рефакторингу та підтримки backend-продукту, проєктування сервісної архітектури й виправлення проблем у наявних системах.

Для Billing-напряму маю також давніший, але прямий доменний досвід. У 2014–2015 роках у CoinsBank/bit-x я інтегрував Stripe, PayPal і Skrill у компоненти платформи, пов'язані з фіатними коштами. У попередніх freelance-проєктах також реалізовував інтеграції зі складними банківськими платіжними системами. Це підтверджує практичний досвід роботи зі сторонніми платіжними API та додає доменний контекст до моєї сучасної експертизи у проєктуванні надійних інтеграційних сервісів.

Мене приваблює можливість працювати саме над бізнес-критичним Billing backend у мультипродуктовій компанії, чиї сервіси мають мільйонну аудиторію. У такому середовищі якість архітектури, стабільність інтеграцій і продуктивність коду безпосередньо впливають на продукт. Водночас роль поєднує підтримку та рефакторинг наявних компонентів із можливістю створювати нові сервіси — баланс, який добре відповідає моєму досвіду розвитку production-систем. Мені також близький акцент Brainstack на менторстві та професійному зростанні: у своїх lead-ролях я ділився знаннями, розвивав інженерів і водночас продовжував навчатися сам.

Буду радий обговорити, як мій досвід у PHP-розробці, системному дизайні, оптимізації та платіжних інтеграціях може бути корисним Billing-команді Brainstack. Дякую за розгляд моєї кандидатури.
