# Backend Tech Lead (Java/PHP)

Posted: 2026-08-18

**🚀 AIMPROSOFT is looking for a Backend Tech Lead (Java/PHP)!**

Aimprosoft is looking for an experienced **Backend Tech Lead (Java/PHP)** to join a telecom transformation project on a full-time contract basis (**6–12 months**).

You’ll take technical ownership across two connected development streams — modernization of an existing broadband platform and development of a new customer-facing portal.

**🎯 About the project & role**

The client is an established UK telecom service provider undergoing a major platform transformation.

The project combines two parallel streams. The first focuses on stabilizing and modernizing an existing **PHP-based broadband platform** hosted in AWS, restoring critical telecom capabilities and integrations. The second involves building a new customer-facing portal with a **Java backend and React frontend**.

As a **Tech Lead**, you’ll lead technical discovery, define the target architecture and ensure architectural alignment between the legacy and new platforms. This is a hands-on leadership role combining solution design, technical leadership, and work with critical parts of the codebase.

**Your responsibilities will include:**

- Leading technical discovery and defining the target architecture and modernization strategy
- Analyzing and modernizing the existing PHP platform, AWS dependencies, and integrations
- Driving the architecture of the new Java backend and its integration with the React-based portal
- Designing APIs and integration contracts between legacy, new, and external systems
- Leading technical implementation across both modernization and new development streams
- Establishing technical standards and reviewing critical designs and code changes
- Mentoring engineers and collaborating closely with client and project stakeholders

**🔥 What We Need From You**

- 10+ years of software engineering experience with proven **Tech Lead / Solution Lead** experience
- Strong and recent commercial experience with **Java** and solid previous hands-on experience with **PHP**
- Strong experience with **AWS**
- Experience in the **Telecom domain** (BSS/OSS, ISP/Broadband, provisioning, order management, billing, CRM, or similar)
- Strong experience with **system integration, API architecture, distributed systems, and Kafka or similar messaging technologies**
- Experience modernizing complex legacy applications and working with SQL databases
- **Upper-Intermediate+ English (B2+)**

**📌 Nice to have**

- Experience with broadband ordering, provisioning, or **Lead-to-Cash** processes
- Experience integrating with telecom wholesale/network providers
- Experience with **Salesforce integrations**
- Experience migrating applications between AWS environments/accounts
