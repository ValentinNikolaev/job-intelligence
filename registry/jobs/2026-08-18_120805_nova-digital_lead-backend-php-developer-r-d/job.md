# Lead Backend PHP Developer (R&D)

Posted: 2026-08-18

**Nova Digital** — це технологічне серце екосистеми NOVA, де твій код стає частиною щоденного життя цілої країни.

**Про масштаб наших сервісів:**

- **50+ млн** запитів щодня проходять через наші системи.
- **10+ млн** активних користувачів покладаються на наші рішення.

**Ми будуємо не просто продукт **— ми створюємо технологічну інфраструктуру, яка об’єднує людей, бізнеси та можливості вже майже по цілому світу.

Шукаємо **Lead Backend PHP Developer** у наш відділ досліджень та розробки (**R&D**). Основна місія нашої команди — швидка перевірка бізнес-гіпотез, створення технологічних прототипів (**PoC**), запуск життєздатних **MVP** та їхня подальша підготовка до масштабування у продакшені. Тобі траба інтегрувати нові рішення з безліччю існуючих систем компанії (включаючи суміжні технічні відділи) та шукати найефективніші інженерні шляхи реалізації ідей на власних серверах та у хмарі GCP.

**Що робитимеш як Lead PHP Developer:**

- **Швидка розробка PoC та MVP:** Проєктування та розробка архітектурних прототипів для швидкого тестування нових продуктів і функцій (від ідеї до першого робочого пілоту).
- **Технічне лідерство та менторинг:** Вести напрямок PHP-розробки, проведення код-рев’ю та розвиток інженерів.
- **Крос-сервісна інтеграція: **Інтеграція нових рішень з існуючими системами компанії та безпосередня взаємодія з командою AI-розробки для безшовного підключення ШІ-модулів, розумних агентів чи моделей аналізу даних до бекенду.
- **Проєктування архітектури:** Підготовка, обґрунтування та захист архітектурних концепцій (ADR) перед Архітектурним комітетом для рішень, що готуються до масштабування.
- **Розгортання та інфраструктура:** Робота із сервісами як на власній On-Premise інфраструктурі компанії, так і в хмарі GCP.
- **Підготовка до Production:** Трансформація успішних прототипів у стабільні, високонавантажені сервіси з урахуванням вимог до безпеки та продуктивності.
- **Моніторинг та аналіз:** Впровадження інструментів для відстеження поведінки та метрик нових сервісів під час пілотних запусків (Grafana, Graylog).

**Твій ідеальний профіль:**

**Must-have:**

- **Досвід:** Від 5 років комерційного досвіду розробки на PHP (7-8 версії) та успішний досвід управління командою або технічного лідерства (Tech/Team Lead).
- **Стек:** Глибокі знання **Laravel**, досвід швидкого розгортання проєктів за допомогою сучасних інструментів екосистеми.
- **Бази даних та черги:** Впевнена робота з PostgreSQL (або іншими реляційними БД) та брокерами повідомлень (**RabbitMQ** чи аналогами).
- **Гнучкість та швидкість розробки:** Вміння швидко будувати архітектуру «з нуля» для PoC/MVP, балансуючи між швидкістю запуску та чистотою коду.
- **Досвід інтеграцій:** Практичні навички проектування та розробки REST API, gRPC, WebSockets, вміння розбиратися в чужих API та legacy-коді для інтеграції сервісів.
- **AI-орієнтованість:** Інтерес до сфери штучного інтелекту, розуміння принципів роботи API сучасних LLM (OpenAI, Claude тощо) та готовність розробляти інфраструктуру під AI-рішення.
- **Архітектурні патерни:** Розуміння DDD, монолітно-модульної та мікросервісної архітектур.
- **DevOps інструменти:** Практичний досвід роботи з Docker, Kubernetes (K8s) та системами контролю версій (Git/GitLab).
- **Мови:** Впевнене володіння українською мовою, англійська — B1 (на рівні здатності вільно читати технічну документацію та вести комунікацію.)

**Nice-to-have:**

- Досвід роботи з асинхронним PHP та інструментами підвищення продуктивності (**Laravel Octane**, RoadRunner, Swoole).
- Досвід роботи з хмарною платформою **GCP** (Google Cloud Platform) та побудови рішень на власній **On-Premise** інфраструктурі.
- Досвід роботи чи розуміння принципів роботи з MPP-базами даних (бажано **Apache Doris** або аналогами для швидкої аналітики великих обсягів даних).
- Розуміння концепцій **Event-Driven Architecture (EDA)** та досвід побудови систем, що реагують на події.
- Досвід роботи в логістиці, стартапах, e-commerce або фінтех-проєктах.

- **Технологічний драйв:** Можливість постійно експериментувати з новими підходами, технологіями та сучасними БД (як Apache Doris) без рутини довготривалої підтримки одного моноліту.
