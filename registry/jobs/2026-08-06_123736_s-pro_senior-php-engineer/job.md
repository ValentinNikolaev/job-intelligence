# Senior PHP Engineer

Posted: 2026-08-06

We are looking for a Senior PHP Engineer to join an Israeli fintech company developing a large-scale online marketplace. The platform has been evolving for many years and is currently undergoing a major modernization initiative focused on improving architecture, performance, and maintainability.

As part of the team, you will play a key role in refactoring legacy components, migrating them to modern PHP and Laravel versions, and helping shape the platform’s future architecture. AI-powered development is an integral part of the engineering workflow, with tools like Claude used to accelerate delivery while maintaining high code quality.

### Responsibilities:

- Refactor and modernize existing PHP applications.
- Migrate legacy functionality to modern Laravel and PHP versions.
- Optimize application performance and improve code quality.
- Analyze, review, and improve AI-generated code where appropriate.
- Write clean, maintainable, and well-documented code.
- Create meaningful logging and improve system observability.
- Work with Docker-based development environments.
- Collaborate closely with the engineering team to deliver features within ambitious timelines.
- Participate in troubleshooting, debugging, and continuous improvement of the platform.

### What you will bring:

- 8+ years of commercial PHP development experience.
- Strong experience with native PHP and modern PHP.
- Hands-on experience with Laravel.
- Solid knowledge of MySQL.
- Experience working with Docker, Redis, and Git.
- Strong background in refactoring and optimizing large existing codebases.
- Ability to understand, review, and improve AI-assisted code rather than relying on generated output without validation.
- Strong analytical and problem-solving skills.
- Good communication skills and ability to work in a collaborative environment.

### Nice to Have:

- Experience with AWS.
- Experience with MongoDB.
- Experience performing manual testing during development.
- Experience modernizing legacy enterprise applications.
