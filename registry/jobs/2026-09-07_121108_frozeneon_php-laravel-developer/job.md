# PHP Laravel Developer

Posted: 2026-09-07

### Обов’язки

- Розробляти та підтримувати фічі у високонавантаженому моноліті, мікросервісах та внутрішніх пакетах (shared-бібліотеки, SDK).
- Інтегрувати API та платіжні системи, працювати з вебхуками та постбеками.
- Оптимізувати MySQL-запити, кешування через Redis та фонові задачі через RabbitMQ.
- Писати код, безпечний для конкурентного виконання, використовуючи локи, м’ютекси та атомарні операції.
- Проводити code review, брати участь у прийнятті технічних рішень, підтримувати статичний аналіз (PHPStan / PHPCS) та тести.

### Вимоги

- 2–3+ роки досвіду з PHP, впевнене знання Laravel (події/слухачі, черги, DI, сервіс-провайдери, FormRequest).
- Розуміння та практичне застосування принципів SOLID.
- MySQL: індекси, план виконання запитів, оптимізація важких вибірок; Redis.
- Досвід роботи з чергами (RabbitMQ) та асинхронною обробкою.
- Розуміння race conditions та способів їх запобігання.
- Досвід інтеграції REST API та платіжних систем, HMAC-підписів, ідемпотентності вебхуків.
- Git / GitHub Flow, робота через PR та code review.
- Docker для локальної розробки.
- Практичний досвід роботи з AI-агентами для програмування — Claude Code, Codex або аналоги (див. нижче; це не «плюс», а щоденний інструмент у команді).
- Робота з Claude Code — очікується.
- Уміння працювати з агентом у великій legacy-кодовій базі: правильно задавати контекст, використовувати CLAUDE.md, memory та посилання на файли.
- Уміння розбивати задачі на етапи, використовувати Plan Mode та паралельних сабагентів.
- Уміння налаштовувати власний інструментарій: slash-команди, скіли, хуки, MCP-сервери.
- Використовувати агентів у CI: для автоматичного review PR, статичного аналізу та генерації тестів.
- Критично оцінювати результати роботи агента: перевіряти дифи, розуміти, де модель може галюцинувати; відповідальність за замерджений код лежить на розробнику, а не на агенті.
- Розуміти вартість та обмеження контексту: вміти визначати, коли делегувати задачу агенту, а коли виконати її самостійно.

### Буде плюсом

- Ubuntu, Nginx, PHP-FPM, cron.
- CI/CD (GitHub Actions).
- AWS та моніторинг Grafana.
- Досвід роботи з антифродом, аналітикою даних, A/B-тестами.
