# Middle+ PHP Developer

Posted: 2026-08-05

**SendPulse** — українська платформа email-маркетингу та чат-ботів для бізнесу. Наразі ми шукаємо **Middle+ PHP Developer** у мультикоманду, яка розробляє **CRM-систему** та **освітню платформу**.

Стек: PHP 8, Laravel, MySQL, PostgreSQL, RabbitMQ, Redis, Docker, Docker Compose, AWS, Nginx
Команда: 4 Backend Developers, 5 Frontend Developers, 4 QA Engineers, Product Manager, Designer

**Що для нас важливо:**

- Впевнений досвід комерційної розробки на PHP 8 та Laravel.
- Глибоке розуміння екосистеми Laravel: Routing, Middleware, Eloquent ORM, Queues, Jobs, Events, Service Container, Artisan.
- Хороше знання принципів OOP, SOLID, KISS, DRY.
- Досвід роботи з MySQL та PostgreSQL.
- Досвід використання RabbitMQ або іншого брокера повідомлень.
- Впевнене володіння Git, Docker, Composer, Xdebug.
- Досвід роботи в Agile/Scrum командах.
- Технічна англійська.

**Буде плюсом:**

- Досвід налаштування CI/CD pipelines (GitHub Actions, GitLab CI).
- Досвід роботи з інструментами моніторингу та логування (Sentry, Grafana).

**Ми активно використовуємо AI-інструменти в розробці, тому очікуємо:**

- Практичний досвід роботи з AI-помічниками: Claude, GitHub Copilot, Cursor, ChatGPT.
- Вміння критично аналізувати, валідувати та рефакторити код, згенерований штучним інтелектом.
- Використання AI для автоматизації рутинних задач: написання базових unit-тестів, генерації документації (PHPDoc, Swagger/OpenAPI) тощо.
- Ефективне застосування LLM для пришвидшення дебагінгу, аналізу логів, траблшутінгу складних помилок та пошуку оптимальних алгоритмічних рішень.

**Чим будете займатися**

- Проєктувати та реалізовувати нові модулі платформи.
- Розробляти інтеграції з внутрішніми та сторонніми сервісами.
- Оптимізувати систему для роботи під високим навантаженням.
- Брати участь у проєктуванні архітектури та прийнятті технічних рішень відповідно до бізнес-потреб.
