# Software Engineer

Posted: 2026-07-25T12:25:05Z

### Overview

The Software Engineer is an integral part of our engineering team, responsible for the design, implementation, testing, and maintenance of innovative software products. The successful candidate must be able to quickly learn the existing systems and components, actively participate in expanding the current systems with new functionality, as well as develop new components using big data and other emerging technologies. We are looking for people who have strong knowledge of Java frameworks, and experience in developing server-side and/or client-side web application components.

### Responsibilities

- Participate in defining product-level architecture and be responsible for designing component-level architecture.

- Take ownership of features and components.

- Utilize test-driven development approach to deliver commercial-quality code.

- Perform code and design reviews.

- Perform hands-on development and maintenance of software applications/components.

- Maintain and support current systems and ongoing programs.

### Qualifications

- BS in Information Systems, Computer Science, Engineering, or a related field required.

- 3+ years of hands-on coding experience in Java; preferably through several complete development cycles from specifications to software delivery.

- Solid knowledge of Java-related technologies like Spring, spring-boot, spring-cloud, JPA.

- Knowledge of any JavaScript framework like Angular is plus.

- Experience in working with microservices.

- Experience working with relational databases, SQL/NoSQL.

- Experience working with distributed web applications and multi-threaded systems.

- Able to learn quickly and effectively apply new knowledge, demonstrating the desire to stay in touch with emerging technologies.

- Must be a disciplined adherent of proper software development procedures and documentation.

- Must be able to work well in a diverse team environment.

- Ability to work independently with minimum guidance.

- Experience in test-driven development through JUnit, and Mockito is a plus.

- Experience with Agile Development & Continuous Integration is a plus.
