## Context

Deda.Next is part of Deda Group and specializes in digital transformation for
public administrations and public-service companies through the design and
implementation of new-generation services. The role is in the Solution Hub
division.

As a Backend Developer specialized in PHP, the person will work on backend
components, APIs, and application services for cataloging, search, and digital
heritage consumption platforms, collaborating with multidisciplinary teams.

## Responsibilities

- Develop and maintain backend components in PHP for cataloging, search, and
  digital heritage consumption platforms.
- Design and implement secure, scalable, well-documented REST APIs for
  integration with frontend applications and third-party systems.
- Work with modern PHP frameworks such as Laravel or Symfony, applying
  architectural patterns and development best practices.
- Manage relational database integration, including data modeling, queries,
  performance, and information quality.
- Develop application services for digital content and asset management,
  including workflows, metadata, permissions, and publishing processes.
- Implement authentication, authorization, and application-security logic in
  line with project requirements and client policies.
- Collaborate with frontend, UX, DevOps, and functional teams to ensure
  end-to-end integration, code quality, and solution continuity.
- Optimize backend performance, reliability, and maintainability through
  testing, code review, logging, and application monitoring.

## Requirements

- Solid backend development experience with PHP 8.x.
- Knowledge of modern MVC PHP frameworks such as Laravel or Symfony.
- Experience with REST API architectures and integration with external
  services.
- Familiarity with authentication and authorization systems such as OAuth2,
  OpenID Connect, and JWT.
- ORM usage and relational database management with MySQL/PostgreSQL.
