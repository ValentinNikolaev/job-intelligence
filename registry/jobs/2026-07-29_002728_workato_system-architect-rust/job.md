# **Responsibilities**

Engine team owns three components used company-wide: Workato Expression Language (our original mini-language for data transformation in recipes), Data Mapper (a new, UI-oriented mapping and format-transformation component), and Decision Engine (a rules component, currently static-only, being expanded to support formulas). The stack is a Rust core with WASM sandboxing per component, with bindings into Ruby and GO.

In this role, you will also be responsible to:

-

Design and build core language and runtime features across the Expression Language, Data Mapper, and Decision Engine.

-

Own and extend the Rust core, embedding it as a native component inside Ruby and Go services via FFI bindings.

-

Help expand Decision Engine from static rules to support formulas.

-

Contribute to WASM sandboxing so each component runs safely isolated from the others.

-

Partner closely with Product and with the AI team on what these components need to expose.
