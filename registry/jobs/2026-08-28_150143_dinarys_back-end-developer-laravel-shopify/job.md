# Back-End Developer (Laravel+Shopify)

Posted: 2026-08-28

-Experience working with high-load ecommerce platforms.
-Strong understanding of Shopify architecture, including products, variants, collections, customers, carts, checkout, orders, fulfillments, discounts, and metafields.
-Experience developing custom backend functionality for Shopify-based ecommerce solutions.
-Strong knowledge of OOP, SOLID principles, and design patterns.
-Experience with MySQL and/or PostgreSQL.
-Ability to design scalable database architectures and write optimized SQL queries.
-Experience implementing authentication, authorization, API security, and webhook validation.
-Experience integrating third-party systems such as ERP, CRM, payment providers, shipping services, analytics platforms, and other external APIs.

-Experience working with Git and collaborative development workflows.
-Ability to work effectively in cross-functional Agile teams.
-Upper-Intermediate English or higher.
