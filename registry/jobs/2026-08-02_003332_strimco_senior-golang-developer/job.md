# Senior Golang Developer

Posted: 2026-07-27

**Ми — Strimco, українська GovTech-компанія і стратегічний партнер цифрової трансформації держави. Наша команда створює цифрові продукти, які змінюють взаємодію громадян, бізнесу та держави — роблять її простішою, швидшою та прозорішою.**
Зараз ми шукаємо Senior Golang Developer, який долучиться до розробки масштабних державних сервісів та складних backend-рішень. Якщо тобі цікаво проєктувати надійну архітектуру, працювати з високонавантаженими системами, інтеграціями та впливати на технічні рішення продукту — будемо раді познайомитися.

**Що ти будеш робити:**

- Розробка backend-компонентів у ДСК-контурі.
- Реалізація API для взаємодії з іншими компонентами системи.
- Розробка бізнес-логіки, статусних моделей, обробки подій і журналювання.
- Робота з MS SQL Server, оптимізація запитів і підтримка коректної роботи з даними.
- Інтеграція з суміжними системами та сервісами.
- Участь у технічному проєктуванні, оцінці задач і code review.
- Усунення дефектів за результатами тестування, ЦПБ/ІБ-перевірок та приймання

**Що для нас важливо:**

- Досвід комерційної розробки на Golang від 5 років.
- Досвід проєктування та розробки backend-сервісів, REST/gRPC API, інтеграцій між системами.
- Впевнене володіння MS SQL Server: робота зі схемами даних, транзакціями, індексами, stored procedures, оптимізацією запитів.
- Досвід роботи з Docker, CI/CD, Git, Linux-середовищем.
- Розуміння принципів безпечної розробки: авторизація, автентифікація, контроль доступу, аудит дій, захист API.
- Досвід роботи з мікросервісною або модульною архітектурою.
- Уміння писати підтримуваний, документований і тестований код.
- Досвід участі в code review та технічному проєктуванні.
- Готовність працювати в захищеному ДСК-контурі на інфраструктурі Замовника.
- Дотримання вимог інформаційної безпеки, обмежень доступу та внутрішніх регламентів роботи з чутливою інформацією

**Буде плюсом:**

- Досвід розробки державних інформаційних систем або систем із підвищеними вимогами до безпеки.
- Досвід роботи з КЕП, журналюванням дій користувачів, audit trail.

- Досвід роботи з MS SQL Server у production-середовищах.
