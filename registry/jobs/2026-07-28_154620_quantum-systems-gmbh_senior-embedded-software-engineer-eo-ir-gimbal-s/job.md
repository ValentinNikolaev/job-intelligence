# Senior Embedded Software Engineer – EO/IR Gimbal Systems (m/f/d)

Posted: 2026-07-28T14:50:45Z

We are seeking a highly skilled **Senior Embedded Software Engineer** to lead the development of software for next-generation defense-grade Electro-Optical/Infrared (EO/IR) gimbal systems. The successful candidate will architect and develop high-performance, low-latency video processing and streaming software for embedded computing platforms while integrating cameras, sensors, communication interfaces, and embedded hardware into a mission-critical stabilization and targeting system.

This role requires strong expertise in embedded Linux, multimedia frameworks, GPU-accelerated computing, networking, and hardware/software integration. You will collaborate closely with systems, electronics, computer vision, mechanical, and control engineers to deliver robust, production-ready solutions for demanding defense applications.

#### **What is your Day to Day Mission:**

-

Design, develop, and maintain embedded software for defense-grade EO/IR gimbal systems.

-

Develop real-time video capture, processing, encoding, decoding, recording, and streaming applications on embedded Linux platforms using GStreamer, FFmpeg, and hardware-accelerated multimedia frameworks.

-

Develop reliable networking solutions for real-time video transport using RTP, RTSP, UDP, TCP, H.264, and H.265.

-

Develop high-performance image processing and computer vision applications using CUDA, OpenCV, or equivalent GPU-accelerated technologies where applicable.

-

Integrate visible, infrared, and thermal imaging sensors into embedded systems.

-

Develop software interfaces for IMUs, laser rangefinders, and other mission-critical sensors.

-

Develop Linux device drivers and perform kernel-level integration for custom hardware.

-

Interface with embedded hardware using SPI, I²C, UART, CAN, GPIO, USB, Ethernet, MIPI CSI, HDMI, and other industry-standard interfaces.

-

Optimize software for deterministic performance, low latency, and efficient utilization of CPU, GPU, and hardware accelerators.

-

Design scalable communication architectures between embedded processors, payload controllers, flight controllers, and external systems.

-

Support hardware bring-up, integration, debugging, verification, and field testing.

-

Implement logging features and analyze issues reported by testing and customers

-

Produce software architecture documentation, interface specifications, and technical documentation.

-

Participate in system architecture, design reviews, and technology roadmap planning.
