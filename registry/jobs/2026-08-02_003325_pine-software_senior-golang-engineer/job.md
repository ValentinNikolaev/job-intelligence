# Senior Golang engineer

Posted: 2026-07-31

Pine Software Technology Ltd is a software company specializing in trading technology solutions for regulated brokers and trading firms. We build SaaS products that support electronic trading, brokerage operations, risk management, and financial data analysis. We are looking for a Senior Go Engineer to join our team.

**Responsibilities**

— Build and ship production services hands-on in Go — from data ingestion through to public APIs.

— Design and evolve our data model and database layer for correctness, performance, and safe schema changes.

— Build reliable, event-driven data pipelines with strong delivery and consistency guarantees.

— Set engineering standards and run code review as the team’s quality gate.

— Own service reliability, observability, and performance, and lead production issue resolution.

— Mentor engineers and collaborate with upstream data providers and downstream consumers.

** **

**Requirements**

— 5+ years building production backend services, with 3+ years of hands-on Go.

— Strong command of Go concurrency, error handling, interface design, and testing.

— Deep experience designing and operating microservices in production — service boundaries, idempotency, resilience.

— Hands-on with event-driven systems and message streaming (e.g. Kafka): delivery guarantees, idempotent consumers, schema evolution.

— Expert relational database and SQL skills (PostgreSQL preferred): data modeling, query performance, safe migrations.

— Experience leading a team or owning a system end-to-end — setting technical direction, code review, and mentoring.

— Clear written and verbal communication, including design documentation.
