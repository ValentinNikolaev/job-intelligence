# PHP Fullstack Developer (Vue.js)

Posted: 2026-08-11

Ми — продуктова компанія, яка розробляє систему **Електронний Кабінет Бухгалтера (ЕКБ)** — SaaS-рішення для автоматизації роботи бухгалтерів, яке виходить на зовнішній ринок у 2026 році.

Шукаємо **PHP Fullstack Developer (Vue.js)**, який буде працювати над розвитком продукту, брати участь в архітектурних рішеннях і впливати на якість системи.

### Основні задачі:

- Розробка backend на **PHP 8.2+ / Laravel 12**
- Розробка frontend на **Vue 3 / Nuxt 4 + TypeScript**
- Робота з **PostgreSQL** (складні запити, оптимізація)
- Інтеграції зі сторонніми сервісами (ДПС, КЕП, банки, Telegram API)
- Робота з **Redis**, кешування та оптимізація продуктивності
- Використання **Docker / docker-compose**
- Code review, участь у технічних обговореннях
- Документування рішень у GitLab Wiki

### Вимоги:

- 3+ роки комерційного досвіду з PHP (Laravel)
- 2+ роки досвіду з Vue.js / Nuxt
- Впевнене знання PostgreSQL
- Розуміння SOLID, патернів проєктування
- Досвід роботи з REST API
- Досвід роботи з Docker
- Самостійність та відповідальність

### Буде плюсом:

- Elasticsearch, RabbitMQ
- Досвід у B2B SaaS / fintech продуктах
- Інтеграції з державними API

### Ми пропонуємо:

- Повністю віддалену роботу
- Гнучкий графік
- Роботу над реальним продуктом, який виходить на ринок
- Сильну команду без бюрократії
- Випробувальний термін — 3 місяці
