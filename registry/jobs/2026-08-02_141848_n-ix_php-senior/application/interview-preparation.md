## Technical Interview

**High Priority:** PHP, Laravel, Symfony, REST APIs, MySQL, PostgreSQL, Elasticsearch, RabbitMQ, legacy-system assessment, technical documentation, migration planning, production troubleshooting, API/query performance, system integration.

Why: These map directly to the vacancy and the strongest source evidence.

**Medium Priority:** AWS, Kubernetes, Helm, GitHub Actions, ArgoCD, microservices, event-driven systems, monitoring, Prometheus, CI/CD, compliance-driven backend work.

Why: These support modernization and delivery credibility, even if the role is primarily PHP.

**Low Priority:** Go, OpenAI-powered automation, email infrastructure, DKIM/SPF/DMARC, blockchain/NFT.

Why: These show breadth but should not distract from PHP and system modernization unless the interviewer asks.

Technical questions to prepare:

- How would you approach discovery of a legacy PHP application?
- What artifacts would you produce after discovery?
- How do you identify risky dependencies before a migration?
- How do you design a migration plan that keeps production stable?
- How do you profile slow APIs and database queries?
- How do you decide between refactoring, rewriting, and strangler-pattern migration?
- How do you document architecture for developers and non-technical stakeholders?
- How do you test integrations between legacy and new systems?
- How do you troubleshoot intermittent production failures?
- What Laravel/Symfony practices help keep large PHP systems maintainable?
