# Built In source status

The requested "build in" source was verified as the **Built In** job board.
Built In currently has no documented public jobs API or RSS feed, and its terms
prohibit automated bots, crawlers, scrapers, and similar extraction mechanisms.
This repository therefore does not install an HTML scraper or reverse-engineer
the internal API referenced by page scripts.

A future collector requires written permission or a documented, licensed feed
from Built In. The stable source name will be `builtin` and the numeric job ID
should be preserved when an authorized integration becomes available.

- Terms: https://builtin.com/community-terms-of-use
- Robots policy: https://builtin.com/robots.txt
