# remoteok remote feed pilot

Enabled through 2026-10-24 inclusive (UTC). Uses the published public interface,
retains attribution and original dates, and excludes unknown geography, stale
records, unrelated roles and incomplete descriptions.

See [European remote source policy](../../docs/europe-remote-sources.md) for
request bounds, provider terms and pilot evaluation. This collector participates
in the existing six-hour collection schedule and makes no requests after expiry.
