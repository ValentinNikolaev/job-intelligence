# Career Hound source status

Evaluated on 2026-11-22. Career Hound indexes company career pages and links
to employer postings. Use the search page for manual discovery and verify
the vacancy on the employer's site.

Section 7 of the terms requires written permission for automated access.
No supported public jobs API or RSS feed was found. Automated collection
would require written permission or a licensed feed.
